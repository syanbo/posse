# Posse 桌面端设计规范

写 `internal/app` 界面时遵守的规则。取值都定义在 `internal/app/style.go`，调用处只用名字，不写数字、颜色值、投影；`fonts_test.go` 的测试会拦下违规（见文末）。各界面的行为见 `docs/features/ui.md`。

## 取向

照 Claude 桌面端的克制：暖灰底色、细线分层、少用粗体、强调色只做强调，界面安静、有层次。参考资料只借原则，数值以离屏预览的观感和对比度为准。

- 每个维度只留少数几档，相邻两档要差得开；同一种东西在每个页面都用同一档。
- 要让信息次要，先换次要色（`TextMuted`），不要再缩小字号。
- 强调色（陶土色）只用在主按钮、焦点、工作中的星号、链接、图标和选中项的淡底（不画竖条）；悬停是中性的 `wash`。
- 只有「待处理」用琥珀色（`honey`）并配文字，是界面上唯一醒目的东西。
- 状态靠形状区分，颜色只是辅助：工作中是星号（减少动态效果时是实心蜂巢格），启动中是空心蜂巢格；看过的本轮完成不画（多数会话平时就停在这里，画了冲淡要处理的几种），没看的是铃铛。
- 每个 agent 有自己的色块图标（`agentTile`）。
- 路径、分支、命令用等宽字体和次要色；一行里的几项靠间距和图标分开，不用「A · B」中点串。
- 历史页的对话装在一张卡片里（和上面的会话信息卡片同一层底色），铺满卡片宽，文字离卡片边 `cardPad`；助理正文不另装框，用户消息是靠右的淡底圆角块，不加边线，最宽是版心的八成。
- 数字用等宽数字（`FontFeatures("tnum")`）；超长路径随处折行；可滚动列表在还有内容的一边渐隐。
- 悬停和按下即时反馈（`hover`，≤120ms 缓出，按下缩放 0.98）。自动播放的动画只表示状态（工作中的星号、等待的波形、未读的铃铛、启动加载），系统设了减少动态效果时都停下。

## 字号

正文字号来自设置（`fsBody`，默认 14），其余由它推出，相邻差 2。

| 名字 | 用途 |
|---|---|
| `fsSmall` | 说明、计数、快捷键、徽标、路径、时间、作者 |
| `fsBody` | 正文、列表、侧栏、按钮、输入框、错误提示 |
| `fsTitle` | 卡片和对话框标题（`titleText`） |
| `fsPage` | 页面标题、空状态标题 |
| `fsCode` | 作为一行主要内容的等宽字（分支名、版本号）；等宽字显大，比正文小一号才看着一样大 |

- 放在正文、元信息里的路径、命令用 `fsSmall`。
- 行高：正文段落 1.6，长段说明 1.5 到 1.55，表格 1.45，标题 1.3 到 1.35；单行列表行用固定行高（见「尺寸」）。
- Markdown（文件预览、历史页的回复、任务说明，`mdView`）照 GitHub 的样式（github-markdown-css）排，不用上面的档位：正文字号是设置里的 Markdown 字号（没设时同 `fsBody`），GitHub 正文 16px 时的尺寸按比例换过来（`mdView.em`）。字号：h1 到 h6 是正文的 2、1.5、1.25、1、0.875、0.85 倍，行内代码、代码块和 `<kbd>` 0.85 倍（`<kbd>` 画不了 GitHub 的键帽边框，同行内代码），`<small>` 0.9，`<sup>`、`<sub>` 0.75（只缩小，不上下移）；行高：正文、列表、表格 1.5，代码块 1.45，标题 1.25；块间距：一般 16，标题上面和分割线上下 24，不看源文件里的空行；列表标记栏 2em、项之间 .25em，嵌套的有序列表依次是数字、罗马数字、字母；h1、h2 下面一条 `hairline` 细线，h6 用次要色；引用左边 .25em 竖线、内容隔 1em 用次要色；分割线是 .25em 高的 `line` 色带；代码块 `code` 底、圆角 `rRow`、内边距 16，复制按钮悬停时浮在右上角；行内代码 `code` 底、圆角 `rRow`、正文色；链接一直带下划线；表格每格四边 `hairline`、内边距 6/13、表头加粗不垫底，表体偶数行垫 `code` 底。YAML 头部是 Posse 自己的属性列表，`fsSmall` 那一档。
- `MeasureText` 用和绘制相同的字号、字重；按内容量好并缓存的宽度（如 `mdTableSize`）要在字号、字重变化后重量。
- 终端和编辑器的字号、字重各自在设置里，不在这套阶梯里。

## 字重

| 名字 | 用途 |
|---|---|
| `fwBody` | 正文；经 mygo 的 `Theme.FontWeight` 设在根节点，不设字重的文字都继承它 |
| `fwMedium` | 列表主标题、按钮、强调的数字 |
| `fwBold` | 标题、Markdown 标题和加粗、「待处理」「已完成」 |

- 已经比旁边大一档的元素不再加粗。
- 选中的列表项只换底色，文字不加粗。标签页也一样：选中换底色、文字从次要色换成正文色（加粗的话长标题截断的位置会变，切换时文字跳动）。
- 界面文字默认不用系统字体平滑（`uiSmooth`）：平滑会让深色底上的浅色字重一档。

## 图标

| 用途 | 图标 | 按钮框 |
|---|---|---|
| 文字旁的图标（箭头、分支、文件、关闭） | 和那行字同号：`fsSmall` 或 `fsBody` | — |
| 工具按钮、列表行首、菜单项 | `iconSize` | `buttonBox()` |
| 紧凑按钮：列表行内、卡片和浮层里 | `smallIcon()` | `compactBox()` |
| 标签和文件行里的小按钮（关闭、继续、折叠箭头） | `fsSmall` | `miniBox()` |
| 状态图形（侧栏会话行左边的状态槽 `statusSlot`、项目和工作区行尾、标签页上） | `smallIcon()`；挨着小字时 `fsSmall` | — |

文件图标一律经 `fileicons.go`：文件 `fileGlyph`，目录 `dirGlyph`，Git 文件列表 `changeGlyph`，文件标签 `docIcon`，符号链接仍是 `iconFileLink`。图形和颜色按类型定，文件的颜色只取 `palette.data` 的数据色或 `TextMuted`，普通文件夹是 `Accent`；加新类型往 `fileicons.go` 的表里加。

agent 色块：跟在小字旁用 `smallIcon()`，单行列表行首用 `iconSize`，三行的列表项（历史会话）用 `tileMedium()`，空状态和详情页头用 `tileLarge()`。

- 除了文字旁的图标，其余都跟着设置里的「图标大小」变。单独的大图标（视频播放键）写成 `sz(...)`。
- 同一排按钮用同一档；成对的图标（侧栏和文件栏的开关）画成镜像，视觉大小一致。
- 放进固定高度的容器前先算余量：diff 折叠行高 32，扣掉内边距只剩 24，按钮用 `miniBox`，图标调到最大也放得下。

## 间距

只用 **2 · 4 · 6 · 8 · 12 · 16 · 20 · 24 · 32**（`spaceScale`），不跟着字号变。

| 场景 | 取值 |
|---|---|
| 上下叠放的两行字 | 2 |
| 图标和紧挨的文字 | 4 到 6 |
| 一行里的几项 | 8 |
| 列表行 | 外边距左右 6，内边距左右 8 |
| 多行列表项（任务、会话） | 外边距左右 8，内边距上下 8、左右 12，行与行之间 2 |
| 卡片式页面（任务、历史、技能、MCP） | 四周、两栏之间、卡片之间都是 `pageGap`（12） |
| 面板头部、页面左右留白 | 16 |
| 卡片内边距 | `cardPad`；空状态卡片 24 |
| 浮层内边距 | 6 |
| 树每层缩进 | `treeIndent`；侧栏下一层 `navIndent` |
| 侧栏行 | 左右都是 `navPad`；侧栏列表左边 `trafficLightX-navPad`，顶层行首图标和红绿灯的红点左边缘对齐，右边 `navEnd` |
| 顶栏、底栏、状态栏两头 | 图标和文字离窗口、侧栏的边都是 `trafficLightX`（和红点对齐）：放图标按钮的用 `iconBarPad()`，状态栏用 `trafficLightX-chipPad` |

- 对齐用的值写成常量或表达式（如 `groupTextIndent()`、`planNameWidth()+8`），不写算好的数，改了一边另一边跟着变。
- 按内边距算宽度或位置的代码（如 `mdCellPad`、测试里拖动把手的坐标）和内边距一起改。

## 尺寸

行高、按钮高、输入框高和跟着文字的列宽写成 `sz(v)`，按正文字号等比缩放（`v` 是 13 号正文时的值）。同一类列表用同一个行高。已有的：侧栏行 `sz(32)`、`sz(46)`、`sz(64)`（一到三行），`logRowH()`、`fontRowHeight()`、`appNameWidth()`、`sidebarDefault()` 到 `sidebarMax()`（侧栏默认 `sz(272)`、最宽 `sz(420)`；最窄由顶上的磁贴算，`sidebarMin`：一行四块正方形磁贴加五道 8 的间隔，默认字号下 280）。

## 圆角

| 名字 | 用途 |
|---|---|
| `rSmall` | 小标签、小芯片、勾选框、小按钮 |
| `rRow` | 列表行、菜单行 |
| `rControl` | 按钮、输入框、分段控件、文件标签、侧栏行、面板里的内嵌块（也是 mygo 控件的默认圆角） |
| `rCard` | 卡片、浮层、磁贴、图片卡片、代码块 |
| `rComposer` | 发送输入区 |
| `full(h)` | 圆点、胶囊、圆形按钮、细竖条 |

- 嵌套时外圆角 = 内圆角 + 内边距，内外同心：`rCard` 的容器内边距 6 → 行 `rRow`；内边距 8 → `rSmall`；`rControl` 的分段控件内边距 2 → 选项 `rRow`。
- 按用途选档，不按数值：16 高的胶囊写 `full(16)`，不写 `rControl`。
- agent 色块、图标按钮的圆角按尺寸比例算，保留比例。

## 颜色

颜色只在 `style.go` 定义（`posseTheme`、`colors(t)`、`agentIcon` 的品牌色），深浅两套。调用处只用名字，不写 `ui.Hex`、`ui.RGBA`，也不加 `Alpha`（动画调暗传入的颜色、列表两端渐隐除外）。

| 类别 | 名字 | 用途 |
|---|---|---|
| 文字 | `Text`、`TextMuted`、`faint` | 正文、次要、最弱（占位、禁用、不重要的计数），只有三档 |
| 强调 | `Accent`、`AccentHover`、`AccentPressed` | 见「取向」 |
| 语义 | `honey`、`sage`、`sky`、`Danger` | 待处理和提醒、完成和新增、信息（传入的提交、MCP）、错误和冲突 |
| 底色 | `side`、`canvas`、`band`、`card`、`raised`、`shade`、`code` | 侧栏、主区域、顶栏、卡片（和终端同色）、浮层、底栏、代码块 |
| 叠加 | `line`、`wash`、`fill`、`fillHi` | 分隔线和内高光、悬停底、次级按钮底和它的悬停 |
| 淡底 | `soft(t, 色)`、`tint`、`mark`、`markOn` | 语义色的淡底；`tint` 是选中；`mark` 是搜索命中，`markOn` 是查找栏当前那个 |
| 投影和遮罩 | `shadow`、`scrim` | 浮层的投影；压在图片、视频上的深色底 |
| 数据色 | `dataColor(t, i)` | 提交图的线、分支比较的两边、用量的分类，依次取 |
| 固定色 | `white`、`black` | 不随主题变的地方：品牌色块、对勾、二维码白底 |

新语义先找现有名字；确实没有再加进调色板，深浅两套都给。

## 层级和分隔线

分层靠底色明度差和细线；能靠底色分开就不画框，投影只给弹出来盖在内容上面的东西。只经这几个函数，不直接写 `Shadow`、`InsetShadow`、`Border`：

| 函数 | 用途 | 效果 |
|---|---|---|
| `elevCard` | 卡片 | 不描边、不投影，靠比 `card` 暗的 `canvas` 分开 |
| `elevFloat` | 浮层（经 `floating`）、提示 | 浅色 `line` 外框加淡投影；深色内高光加投影 |
| `elevSheet` | 从窗口底边升起的面板 | 顶边一条线 |

- 单闭合边框：从画布往里，一条视线最多穿过一层闭合的框；有框的容器里，按钮和输入用填充或幽灵样式，不再加框。
- 盖在终端上的按钮列用不透明的 `Surface` 底、不描边；填充底的按钮不描边；表格只画行间横线、表头用填充底；代码块标题栏不画线。
- 分隔线颜色一律 `line`，线宽 `hairline`（2 倍屏一个物理像素）。主题的 `Border` 只给 mygo 自己的控件。
- 兄弟元素之间用 `hline(c)`、`vline(c)`；容器自己的边界用 `BorderWidth(hairline, …)`。区域之间的线贴边；列表、菜单里两组之间用 `Margin(4, 6)`；其余跟着容器内边距缩进。
- 聚焦框不是分隔线，粗细 `focusRing`；不聚焦时画同底色的框占住尺寸，聚焦时不挤动内容。

## 改这套规范

1. 改 `style.go` 里的定义，不在调用处单独调；设置项在 `uistate.go`（`ui.json`）和 `settings.go`，经 `setUIType` 生效。
2. 跑 `go test ./internal/app`。守规则的测试：`TestNoLiteralType`（字号、字重、图标尺寸、圆角）、`TestSpacingScale`、`TestColorsInPalette`、`TestElevationAndLines`、`TestSetUIType`。按尺寸断言的测试（表格、拖动把手、开关位置）会指出连带要改的地方。
3. 离屏预览比较前后：`POSSE_PREVIEW_DIR=/tmp/posse-preview go test ./internal/app -run TestPreview`。`ui-small`、`ui-large`、`ui-heavy`、`icons-large` 是设置调到两头的样子。
4. 同步本文和 `docs/features/ui.md`。
