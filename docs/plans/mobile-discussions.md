# 手机端讨论

## 目标与边界

手机通过现有配对、E2EE 和 QUIC 连接操作所选电脑上的讨论，支持本机讨论和该电脑已经分享或加入的多人讨论。手机代表这台电脑的用户，不建立新的协作身份，不直接连接房主的 collaboration 服务；电脑离线时显示断线，不假装发送成功。界面沿用「讨论」命名。

现有依据：`internal/daemon/discussion.go` 已提供消息分页、增量、客户端请求去重、成员与执行操作；`collab*.go` 已在相同入口处理远端房间和拥有者权限。手机服务的 `History` 桥接可作为接入模式，但讨论必须明确列出允许的方法，不能开放通用 daemon RPC。Flutter 首页在 `mobile/lib/workspace/workspace.dart`，历史页提供现有导航及异步加载范式。

## 实现步骤

1. **接入协议和服务端边界**
   - 新增 `posse.discussions.v1` 能力与明确的 Discussion Host 接口，手机服务只开放用户侧讨论方法；复用 daemon 的原有处理函数和事务，不开放 worker 的 read/ack/pending/task done 等接口。
   - 支持列表、详情、搜索、创建、改名、归档/恢复、成员增改删/重启/恢复、发送/引用/@、回答、关键标记、取消/停止/重试/确认/隔离，以及协作分享/邀请/加入/批准/拒绝/移除参与者/退出。按照真实 RPC 参数逐个接入；工作区 ID 在手机组合 ID 和 daemon ID 间显式转换。
   - 明确手机侧身份，不接受客户端伪造 caller 或用户身份；仍由 daemon 校验房主、拥有者、归档、离线、执行状态。错误保留错误码，经连接语言翻译。未知方法和旧电脑给出升级提示。
   - 附件使用受控上传暂存和按讨论/消息/附件 ID 下载，限制数量、大小、分块、文件名和路径；不让手机传入任意电脑路径作为讨论附件。发送成功后清理暂存，断线/取消/超时也回收；复用现有 bulk 能力前先核实授权和大小限制。共享房间继续经现有协作附件流程。

2. **Flutter 数据与同步**
   - 在 `mobile/lib/discussions/` 分离模型、RPC/状态和页面。首页提供讨论入口，按当前电脑加载列表，显示未读和待回答；支持创建、归档列表及加入讨论。
   - 详情初始取最新一页；按消息 ID 合并、序号排序，以 rev 拉增量；支持往前/后分页、搜索定位和引用定位。限定消息窗口（与桌面一致最多 500 条），丢弃对应渲染缓存；阅读旧历史时不把新消息接到旧窗口或抢滚动位置，提供新消息提示和回到最新。
   - 切电脑、切房间、跳转和销毁时使旧请求失效；页面不可见或 App 后台时停轮询，恢复/重连后补齐。列表 seq、详情 rev、历史窗口分开管理，避免过期响应推进游标；大增量需有界回退，避免重连一次加载全部历史。
   - 发送生成稳定 clientId；响应丢失后原样重试沿用 ID，保留正文、引用、@ 和附件。发送中禁止改动同一请求；修改后成为新请求，避免把新正文误当旧发送去重。成员添加也复用现有请求 ID 语义。
   - 草稿与已读按电脑身份和 roomKey 隔离保存；真正看到底部才推进已读，不复用或改写桌面 ui.json。

3. **手机交互**
   - 消息显示作者、时间、Markdown、引用、附件和执行状态；输入区选择一个自己的 Agent 执行，也可提醒参与的人。成员详情明确拥有者，其他人的 Agent 不提供执行按钮；归档只读，离线/待批准/移除状态明确。
   - 待回答的问题支持直接回答；执行操作依状态提供取消、停止、重试、并行确认和独立 worktree。危险操作与放弃旧执行后重发明确确认；打开 worker 时转换到现有手机终端路由。
   - 成员设置可选本机工作区、agent、模型和思考深度；创建 worktree、未知远端结果、配置需要确认等保持桌面语义。详情面板承载成员、关键消息、搜索、协作参与者与管理动作，适配窄屏及键盘。
   - 图片和文件选择、上传进度、失败重试、下载/预览走现有手机组件。颜色字号遵守 `docs/mobile-design.md`；全部界面文字加入中英 ARB 并生成本地化文件，时间遵守系统时制，错误经 friendlyError。

4. **验证、审查和交付**
   - Go 测试覆盖能力门控、方法白名单、身份/参数边界、附件路径和大小限制、daemon 桥接、发送去重、拥有者限制和错误码。
   - Flutter 模型/状态测试覆盖增量合并、旧响应丢弃、分页窗口、断线重试不重复发送、切电脑隔离；widget 测试覆盖列表/消息/@/回答、只读和离线、旧电脑提示、中英布局。使用临时 home/fixture，不启动真实付费 Agent 作为自动测试。
   - 跑 Go build/vet/test、mygo vet/i18n check；手机 gen-l10n、analyze、flutter test。同步 `docs/features/mobile.md` 和 `docs/features/discussions.md`。
   - 开发前交 Claude 对照源码审查本计划，修订后由主 Agent 开发；开发完成再交 Claude 审查代码，修复并回归。
   - 代码审查处理完后，派 Grok 用 droidmirror MCP 做安卓真机验收。连接隔离的 PosseDev（6790，开发 home），不使用日常数据；验证创建讨论/成员、发送/@/回复、回答、分页/引用/附件、断线重连、多人权限和中英深浅外观。需要真实 Agent 执行的验收使用独立测试项目，记录环境、操作、结果和证据；不可验证项明确列出，不当作通过。
   - 不发布、不覆盖日常安装包；真机安装使用开发测试构建并保护原有配对与数据，若工具或设备条件不足先完成其余检查并报告具体阻塞。

## Claude 审查后的实现约束

已采纳 B1–B5：按设备隔离磁盘暂存，只回 stagedId，1 小时 TTL；发送先对账去重再解析暂存。上传采用有界分块 RPC（每块 256 KiB、总量 20 MiB），下载按消息和附件 ID 定位并通过现有 bulk 返回；不复用会泄露绝对路径的 clipboard 上传。镜像附件尚未下载与已缺失分开报错。RPC 错误完整保留 data。详情 limit 封顶 100，rev 跨度超过 100 回 reset 最新页；列表正文截到 200 字符。安卓使用本机 release key 构建并保留数据覆盖安装，签名不符不卸载。

白名单采用报告 S1 的用户侧方法，去掉 caller，join 不接受 addrs；工作区必须是已知的 project::workspace。调用异步执行，界面按操作设超时；回答也带 clientId。前台讨论页每 2 秒轮询，后台停；首次 method_not_found 提示升级电脑。新增讨论系统推送不在本次范围，待处理与未读在讨论列表显示。配置不可信时须保存成员设置确认；不能拿 resume 代替。测试增加 Data、暂存过期同 ID 重试、跨讨论附件访问和大增量 reset。

## 代码审查修订

- H1/M1：增量只更新窗口内消息或追加更新的消息；窗口外旧消息只更新关键列表。旧窗口收到 reset 时按原序号范围补读，刷新该窗口的执行卡，不跳到最新。
- H2/H3：本机讨论成员只列同项目工作区，默认沿用讨论工作区；创建 worktree 的输入只在所选工作区有 Git 分支时显示。member.add 请求发送前按电脑和讨论持久化，结果未知或已建 worktree 时恢复同一表单；确定未执行的错误解锁。手机连接丢失等未知结果同样保留请求。补齐本机添加成员的 clientId 去重，复用已有 AddMemberOnce 和请求工作区记录。
- H4/M2：暂存锁只用于校验和引用计数，网络发送在锁外执行；被发送引用的文件不可清理或取消。分块重复请求校验已写字节后幂等返回，手机对超时分块重试一次。保留设计中的有界 JSON 分块，未引入第二套 bulk 上传登记。
- M3/M4：汇报文件以 hasReport 和按消息 ID 的分块读取接口提供，隐藏本机路径；回答重试按原 clientId/问题/正文确认已经写入的答案，防止把其他人的答案误报为自己的成功。
- 其余：空错误 data 不再发送、镜像文件名使用同一归一化函数、图片预览关闭不触发保存、断线停轮询、规整 null 参数、清理空设备暂存目录。

## 安卓真机验收

Grok 使用 DroidMirror 在华为 CLS-AL30 上连接 PosseDev 6790 验证：创建讨论、消息与分页/引用/关键/搜索、自己的 Agent 提问与回答、文本附件上传下载校验、图片预览关闭不保存、断线草稿、归档恢复、中英深浅及键盘布局通过。补验实际点击取消排队、停止执行，与常驻进程记录的 cancelled/stopped 一致；另用隔离的协作身份和 6794 手机端口验证镜像在线同步、离线仍可读且不可发送、他人 Agent 不可执行或配置。日常配对和原有开发终端保留。

成员添加的明确错误及未知结果重试未在真机安全制造，由 widget 测试覆盖，不能当作真机通过。真机发现的停止确认按钮文案和相册 JPEG 沿用 PNG 文件名已修正；后者按文件头修正上传名，不改文件字节，真实 PNG 保持原名。

修正版 Android 0.1.17（830）已由 Grok 覆盖安装复测：相册转换的 JPEG 上传名及类型为 `.jpg` / `image/jpeg`，从文件选择的真实 PNG 保持 `.png` / `image/png` 且 SHA 不变；停止确认按钮显示「停止执行」，点击后执行状态为 stopped。Claude 复核本轮增量无阻塞，26 项相关自动测试及 Flutter analyze 通过。
