# 看桌面：只看一个窗口

2026-10 定方案。手机屏小，整块 Mac 屏缩下来字看不清；只看一个窗口时同样的像素全给它，放大的需要少得多。

## 关键决策

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 怎么采 | `SCContentFilter initWithDesktopIndependentWindow:`，只采这个窗口 | 别的窗口盖在上面也不进画面；不用裁整块屏（裁的话盖住的窗口、窗口挪走都得自己处理） |
| 画面尺寸 | 窗口的像素大小（点数 × 所在屏的缩放），照旧不超过手机长边，码率低时照旧减半 | 和整块屏走同一套 `Fit`、`CtrlScale`；满码率按窗口尺寸算，小窗口自然用更少的码率 |
| 窗口改大小 | 采集子进程每秒查一次窗口的位置和大小，大小变了按新尺寸重开编码器和采集 | 编码器尺寸是固定的；和改分辨率走同一条路 |
| 窗口列表 | 手机打开选择面板时现要（`desk.windows`），不随订阅推 | 窗口一直在变，推了也很快过时；列表只在要选的时候有用 |
| 列哪些窗口 | 当前空间里看得见的普通窗口（第 0 层、不小于 120×80 点），按前后顺序，最前的在上面；去掉被排除的 App（模拟器）和 Hive 自己的采集子进程 | 别的空间、最小化的窗口点了也操作不了；要看先切空间 |
| 输入 | 手机的 0–1 坐标按窗口当前的位置换算；按下前窗口不在最前就先把它提到最前 | 注入的点击落在屏幕上那个位置，窗口被盖住时会点到上面的窗口；键盘发给最前的 App |
| 提到最前 | 辅助功能：App 设 `AXFrontmost`，窗口执行 `AXRaise`（窗口对应靠 `_AXUIElementGetWindow`） | 采集子进程是后台进程，macOS 14 起 `NSRunningApplication.activate` 从后台调常被拒；Rectangle、AltTab 都这样做 |
| 窗口关掉、最小化 | 回到它所在的那块屏，手机提示一句 | 不能让画面停在最后一帧 |
| 记不记 | 不记。下次观看照旧从记着的屏开始 | 窗口 ID 关掉就没了，重开 App 也会变 |
| 手机入口 | 悬浮球的「屏幕」改叫「画面」，一直显示；面板上面是屏（排布图，只有一块屏时只有一行「整块屏」），下面是窗口列表 | 一块屏的人也要能选窗口 |

## 协议

- 子进程控制：`CtrlWindows`（8）要窗口列表，回一帧 `KindWindows`（6，JSON `{"windows":[{id,app,title,w,h,display}]}`）；`CtrlWindow`（9，u32 窗口 ID）切到窗口。`CtrlDisplay` 切回整块屏。
- `KindDisplays` 加 `window`：正在看的窗口 `{id,app,title}`，看整块屏时没有；窗口没了回到屏时加 `"gone": true`。
- 常驻进程：`desk.windows` 写 `CtrlWindows`，等 `KindWindows`（最多 3 秒）原样回给手机；`desk.window {id}` 写 `CtrlWindow`，切好了由 displays 事件告诉手机。

## 步骤

1. 子进程：窗口列表（`CGWindowListCopyWindowInfo`，前后顺序）、按 ID 取 `SCWindow` 开窗口采集、每秒查位置大小（变了重开、没了回屏）、注入按窗口换算并在按下前提到最前；`rebuildDisplay` 改成切换目标（屏或窗口）的通用重建。
2. 常驻进程和手机服务：`desk.windows`、`desk.window`。
3. 手机：「画面」面板加窗口列表，正在看的窗口打勾；窗口没了提示。
4. 测试：帧和控制的编解码、窗口列表过滤排序、输入换算；开发包实测窗口采集、改大小、关窗口、点被盖住的窗口。

## 未知
