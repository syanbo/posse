# 手机对话页：正在输出的草稿

agent 回复时，手机对话页像终端一样一段段看到正文，不必等整段写进会话文件。只做 Claude、Codex。这里只记依据、取草稿的规则和录制方法，协议和界面行为以 `docs/features/mobile.md` 的 `posse.draft.v1` 为准。

## 依据（2026-10-28 实测）

用测试常驻进程起真实的 Claude 2.1.312、Codex 0.163（100×40），各写约 300 字，每 200ms 读一次屏幕：

| | 屏幕上第一行 | 屏幕上写完 | 会话文件写入正文 | 会话文件比屏幕晚 |
|---|---|---|---|---|
| Claude（418 字） | 发出后 2.4s | 6.2s | 与写完同时 | 约 3.7s，随长度增长 |
| Codex（340 字） | 约 6s | 约 20s | 本轮结束时 | 约 14s |

- Claude 的会话文件按内容块写：thinking、text、tool_use 各在写完时成一行，正文整块到。Codex 的回复在 `task_complete` 前才写。
- 屏幕上的文字是 TUI 渲染过的：按终端宽度硬折行、续行缩进 2 格；Claude 去掉了 `##`、`**`、反引号和代码围栏，表格画成框线；Codex 保留 `## `，列表换成 `•`，代码围栏去掉。所以草稿只当纯文本，正式消息到了再换成 Markdown。
- 回复开头：Claude 是第一列的 `⏺`，Codex 是第一列的 `•`。

## 取草稿（`internal/mobile/draft.go`）

- agent 在干活（hooks 报 working，或者认得出状态行）时取：流式写正文时两家都不画状态行（Claude 的 `✻ …`、Codex 的 `• Working`）。停下后推一次空草稿。
- 从屏幕底部往上找最近一个回复块的开头：Claude 取 `⏺` 开头、不是工具调用（`⏺ Name(…)` 后面跟 `⎿`）的块；Codex 取 `•` 开头、不是 `Working`、`Ran`、`Explored` 这类条目的块。Claude 开始调工具时先只有一行 `⏺ Reading 1 file…`，`⎿` 稍后才画；进行中的工具块头上的 `⏺` 会闪，闪灭时看着像上一块的续行。
- 接回折行：去掉续行的 2 格缩进；上一行行尾和下一行行首都是中日韩文字就直接拼，否则补一个空格；空行保留成段落分隔；框线表格和缩进的代码行原样保留。
- 回复超出一屏：回滚区里没有回复（Claude 每次重画连回滚区一起清掉，Codex 在备用屏幕上），所以每帧只取看得见的部分，和上一帧拼好的接起来（在已拼的行里找这一帧第一行，后面的行也对得上就从那里接上，正在写的末尾几行和空行不比；接不上时中间写 `⋯`）。手机中途才打开对话页时看不到已经滚出屏幕的开头。
- Codex 回复滚出屏幕后，顶上一行钉着截断的用户提示（`› ……`），要跳过；一轮结束后正文下面多出 `└ Tip: …` 和 `Worked for …`。Codex 写完一段重排时偶尔有一帧画错，同一块草稿缩回去时最多按住 4 帧（`draftHold`）。
- 去重：记住会话文件里最近一条助手正文（规范成同样的纯文本），草稿和它相同或是它的前缀就不推。会话文件可能比屏幕上最后一两行先到（Claude 约 0.1s）。

不做：还原 Markdown、Grok 和 Cursor、桌面端。

## 录制（`internal/mobile/testdata/draft/`）

`TestDraftReplay` 逐帧回放这些录制：草稿只增不减、和最终正文的纯文本一致、工具块不进草稿、写进文件后不再推。TUI 改版会让规则失效，Claude、Codex 升级后重录一次对比。

- 每份是 gzip 的 JSON：每 200ms 读一次的屏幕（只留变了的帧）、这一轮写进会话文件的助手正文和写入时刻、录制前最后一条回复（格式见 `draft_test.go` 的 `draftRecording`）。
- 两家各录：超过一屏的长回复（`*-long`）、先调工具再写正文（`*-tool`）、带 Markdown 的（`*-md`，标题、列表、代码、表格、中英混排）；`*-live` 是 iOS 模拟器接测试常驻进程实测时录的。
- 用测试常驻进程（`POSSE_HOME=/tmp/...`）录。它是没签名的 `go build` 二进制，项目放在「桌面」「文稿」下会弹系统授权框挡住它（git、agent 都卡住），录制目录要避开；Claude 用它已信任、不在受保护目录下的目录，Codex 也用已信任的目录。

模拟器实测（iPhone 17 模拟器，真实 Claude、Codex 各写约 1500 字）：Claude 屏幕上第一行 2.24s、手机出草稿 2.20s、会话文件写入 17.81s；Codex 分别是 3.06s、3.35s、83.63s。出草稿的延迟在采样间隔以内，草稿比正式消息早 15s（Claude）、80s（Codex）。
