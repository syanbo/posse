# 文件

文件栏和文件标签，照 Orca 分两处。文件树、文本打开/重载与可见内容轮询按当前主机读取；本机沿用直接读取，远端使用固定身份的目标文件服务。主机入口尚未开放，完整远端文件功能仍在实施。

目标读取服务提供 `files.stat`、`files.readDirs` 和 `files.readRange`，允许桌面查看身份调用，不取控制权。路径明确属于目标主机，批量最多 128 项；逐项报错，不把权限或路径类型错误当成文件缺失。多目录回复共用 4 MiB 保守预算，每批枚举最多 128 项，逐项计费并检查取消；超限立即停止该目录，不把截断列表当完整目录，取消或超时丢弃整批结果。只有预算内完整目录才排序并返回。原始字节每段最多 1 MiB，读前后核对磁盘戳和路径指向，只读普通文件；文件改动返回冲突，软链按目标文件读取。客户端按同一磁盘版本组装文本，保留 5 MiB 只读、50 MiB 不加载限制，并计算内容指纹；原始字节通过 base64 传输，不经 JSON 字符串修复非法 UTF-8。窗口文本读取完成后再核对完整磁盘版本：原始字节摘要、磁盘戳和权限一致才交给编辑器，并保留实际路径与版本；同磁盘戳下分段内容混合也会被拒绝。本机读取同样保留完整版本，编辑器归一化 CRLF 不改变磁盘基线；二进制、目录和过大文件不生成可保存的版本。读取失败不返回部分文本，也不改读本机同名路径。窗口读取失败时保留已有目录树和文本；旧主机、旧重载和保存前的迟到读取不会覆盖新状态。目录轮询与手动加载共用请求序号；有未保存内容的文档只核对磁盘状态，不下载不需要的全文。查看身份的编辑器只读，未保存内容仍保留；Markdown 的 Wiki 链接在目标查询。未迁移的远端 Git 写操作和目录批量传输仍待接通，尚未适配的路径拒绝回退访问本机；远端文件不提供直接访问目标路径的本机访达、默认应用和路径拖出入口；本机应用只能打开明确下载的副本。

目标图片和 Markdown 嵌入图片使用只读 `files.resourceRange`：每段最多 1 MiB，保留原始二进制，读取前后核对根目录身份、实际目标、文件戳及权限。收齐后经同样受根目录限制的 `files.resourceVersion` 核对完整原始字节 SHA-256，防止同磁盘戳下拼接不同内容；失败不交部分正文、不自动重读。资源必须是根内普通文件，根内相对/绝对软链和 `link/..` 按文件系统语义解析，越界拒绝；固定根目录句柄防止检查后改向根外。单独打开的图片按用户所选绝对路径读取，编码数据最多 50 MiB，保留现有像素尺寸、缩放和动图处理；Markdown 资源根是包含文档的工作区，否则是文档父目录，编码数据最多 20 MiB，`/images/x.png` 按资源根解释，不读取根外文件或本机同名路径。缓存归属文档及主机身份，文档版本、路径或身份变化时撤销旧读取，关闭文档取消在途目标请求。单独图片标签关闭或被预览标签替换时也取消读取，迟到回复不创建位图；图片自动重载失败保留已显示内容，后续轮询继续重试，成功后才确认新版本。外部 HTTP(S) 图片仍由窗口下载，但远端文档中的 localhost/回环地址和跳向这些地址的重定向明确拒绝；拨号前核验 DNS 结果并使用核验过的 IP，避免域名解析到本机同端口。此远端图片下载连接不使用环境 HTTP 代理，以免代理再次独立解析目标；普通本机文档沿用原下载方式。目录批量传输仍待后续接入。

远端 HTML 预览使用窗口创建前注册的 `posse-preview` scheme：每次载入分配不可猜测的 token，URL 不包含目标的绝对路径。HTML、CSS、JS、图片、字体等同源文件经 `ReadResource` 分段读取并校验摘要，不交给 WebKit 本机目录权限，也不开本机 HTTP 服务。资源根与 Markdown 一致：文件目录在工作区内时用工作区，否则用 HTML 父目录；`/images/x.png` 按根解释。静态 HTML/CSS 引用改写为资源地址，保留 `link/..` 给目标解析，越界、`~/`、NUL 和根外 `file:` 引用拒绝。交给 WebKit 的 HTML/CSS 中 localhost、`*.localhost`、回环及未指定 IP 引用替换为空白地址；非回环的外部 HTTP(S) 子资源仍由 WebKit 加载。网页链接交给网页标签，根内 HTML 可以继续预览，其他文件导航阻止。关闭标签、换主机或视图代次变化会销毁远端页面并取消读取，文档磁盘戳改变会作废旧 token；每次重新载入仍通过资源服务。首次失败报告错误并保留源码，重载失败保留上次成功页面，不改读本机同名文件。

历史详情里的助手 Markdown 图片复用同一图片加载器：根是绝对的会话 Cwd，否则用会话文件父目录，相对路径和 `/images/x.png` 都受该根约束。远端使用该详情请求捕获的查看身份读取目标资源；换会话、详情请求换代或换主机关闭加载器并丢弃迟到结果，工具文本和会话媒体面板不因此改变。

终端截图粘贴通过写入 `files.pasteImage` 把 PNG 原始字节保存在目标临时目录，成功后才向原终端粘贴目标路径。单张最多 50 MiB，校验 PNG 头和内容摘要，随机文件以 0600 创建，失败或执行取消时清理。它和 `files.save` 共用已接受请求的正文预算及结果去重；查看身份和独立直调不能创建文件，断线不撤销已接受上传，结果未知不重发。窗口回调核对原控制身份和终端视图，不能把结果贴给新接入的终端。成功的目标临时文件保留供 agent 随后读取，不随窗口断开删除。此接口仅用于剪贴板图片。

远端文件栏提供单文件上传与下载副本，每个文件最多 50 MiB。顶部上传按钮写到工作区根目录，目录右键的「上传文件…」写到该目录；本机文件选择器只选源文件，不把本机路径当目标路径。目标同名文件先确认，确认绑定完整版本，确认后被其他程序改动仍拒绝覆盖。上传读取源文件的前后版本和原始摘要，二进制、CRLF 与空文件原样保存，沿用 `files.save` 的控制权、共享预算、资源锁及未知结果语义。文件右键的「下载副本…」在本机选择保存位置，查看身份也能下载；目标资源完整读取并核对摘要后才在本机条件原子写入，读取失败、取消或本机目标被改动不留下半份副本，也不覆盖改动。窗口内的下载与无桌面身份的本机保存共用实际目标路径协调锁，同一路径串行核对和替换，不同路径可并行、等待可取消；外部程序及其他进程不参与此锁，仍有最终检查到替换之间的文件系统竞争窗口。每个工作区同一时间一项传输，文件栏显示文件名和传输状态，完成后提示结果；上传成功刷新文件列表，已打开文档的草稿继续保留，由轮询处理磁盘冲突。文件选择器和覆盖确认绑定原主机身份，切换后不启动旧动作；已经提交的上传不因切换而撤销，不自动重发。远端文件菜单和二进制等内容提示页提供「用本机应用打开副本…」：先在本机「保存副本并打开」对话框选择位置，沿用相同下载校验，成功落盘且原主机身份与文件视图仍有效时才交给本机默认应用。副本修改不回写目标文件；下载失败不打开，打开失败保留副本并分别报告已保存和打开失败。目录批量传输、终端复制/拖入文件仍待后续接入。

远端文件清单与全文搜索通过 `files.list`、`files.search` 在目标执行，快速打开的模糊匹配仍在窗口做。清单保留多仓库、软链别名、单仓库配置和忽略规则；「包括非项目条目」使用目标的完整清单。搜索支持目录范围、大小写、正则、包含/排除和未保存文档内容，目标自己生成搜索清单；显式限定到被忽略的目录时仍可搜索。草稿最多 128 个文件、合计 8 MiB，单个不超过现有可编辑大小限制；清单及搜索回复最多 4 MiB，超限明确报错。窗口按固定主机与查询序号收结果，身份变化后重新读取，失败保留已有清单/命中并显示错误；快速文本查询不必等文件清单返回。

远端符号页通过 `files.symbols` 在目标查找，保留「只看类型」、限定忽略目录和草稿覆盖。跳到定义通过 `files.definition` 将当前文本快照与字节位置交给目标，import 路径、Go/TS 别名、限定符类型和同名定义优先级均在目标解析；源快照沿用 50 MiB 上限，回复沿用 4 MiB 上限。窗口负责单一定义跳转、多候选选择及当前位置定义转为查找用法；主机身份、源文档路径/版本、当前标签或文档存续变化后，旧查询和旧选择框失效，不解析本机同名路径。

条件保存底层已有 `files.ReadVersion/WriteFileChecked`：版本包含读取时的实际路径、磁盘戳、权限和原始字节的 SHA-256；写临时文件前与替换前均核对版本及软链实际目标，取消或失败清理临时文件，成功返回本次写入的版本。路径中的软链与 `..` 按文件系统顺序解释；读取后软链换目标会发生冲突，断链不会被普通文件替换。写入逐块检查取消和 50 MiB 上限，超限不提交；临时文件通过父目录句柄清理，父目录被改名也不遗留未提交内容。调用方仍须持有覆盖整个检查与替换过程的资源协调锁；外部编辑器不参与该锁，最后一次检查到 rename 的竞争仍可能发生。目标端已有只读 `files.version` 与条件保存 `files.save`：前者返回实际路径、磁盘戳和原始字节摘要，明确不存在返回 Missing；后者携带完整基线、原始字节、提交摘要和编辑 revision，在共享路径/common-dir 锁内核对并原子保存。保存必须经桌面执行器接受，查看或过期身份、独立直调均拒绝；提交摘要不符和超过 50 MiB 的内容不写盘。已接受保存的 JSON 总量有独立预算，最多容纳一份 50 MiB 文件的编码请求；在解码正文和启动执行前预留，超额返回忙碌且不消费请求序号，完成或失败后归还，断线和接管不提前释放。回复只有本次写入版本及原 revision，完成缓存不保留文件正文；断线不取消已接受操作，客户端返回原操作引用而不自动重发，可经 `desktop.operation` 查询，实例变化或缓存消失只能视为结果未知。窗口已保存完整读取基线，重载和轮询的迟到回复也核对该版本；编辑器支持按已提交快照设置保存基线，保留后来编辑和撤销历史。窗口保存已改为后台执行，每文档同时只有一份提交；带桌面身份的本机和远端 Client 均经 `files.save`，尚未启用身份的本机窗口暂用同一版本校验原语直接保存。保存前重读完整版本，变化先确认，确认绑定这次版本和提交快照；确认后再变化仍拒绝覆盖。保存成功只标记提交快照，等待期间的新编辑保持未保存；关闭标签、批量关闭和退出须等结果确定并复查草稿，批量覆盖确认逐个处理，取消停止后续保存。保存期间不重载文档；未知回复保留原操作引用与快照，后续保存动作或可见文件轮询先查询原操作，仍在运行则继续等待，完成或未知才读取当前版本。当前内容摘要相同只确认该内容在磁盘上，不声称恢复历史；不同则保留草稿、提示冲突，须重新发起保存和确认，不自动重发。路径迁移后仍先查询原操作，再核对新路径，旧结果不标记新路径文档。本机控制身份和主机选择入口尚未启用，完整远端文件功能仍未开放。

移到废纸篓使用目标只读 `files.entry` 和桌面写入 `files.trash`。确认前读取条目的实际父目录路径、设备/inode、磁盘戳、类型及链接内容；执行时在共享资源锁内再次核对，替换或改动后拒绝旧确认。最终一级软链不跟随，断链和循环链接也按链接本身移动；目录身份核对不递归计算所有后代的内容版本。保存独占实际文件路径，并共享占用途中经过的软链条目（含链接目标内部的链接）；取锁后重新发现这些资源，链接链变化即拒绝。移走链接或其父目录与经它保存互斥；同一链接下的不同文件不会仅因共用链接而串行。异步条目信息返回时也核对确认代次，迟到结果或错误不会替换后来打开的确认。失败不永久删除、不清理窗口文档；未知回复不重发，保留草稿和现有视图，由正常轮询刷新现状。成功只关闭没有草稿且没有待确认保存的标签。窗口带桌面身份时在目标 daemon 调用无界面 Foundation 适配；普通本机窗口尚未启用身份时也使用该适配和条目校验，不再调用需要界面的废纸篓接口。外部程序不参与资源锁，最后检查之后仍有文件系统竞争窗口。

- 文件栏（`filespanel.go`）停靠在主区域最右边，顶栏是"历史""文件""技能"三个图标页签（时钟、文件、星形，`panelTab`；选哪个记在 ui.json 的 `filesPanelTab`，所有项目共用）：
  - 历史是当前项目（项目目录和它的各个 worktree）最近的会话（`recentList`，开着时每 15 秒刷新），点一个跳到历史页打开、悬停时右上角点播放接着聊、右下角点删除移到废纸篓（和历史页的"移到废纸篓"同一套确认，正在终端里运行的不让删，`trashListedSession`）。技能是当前工作区的项目级技能（见 `ui.md` 的技能页）。文件下面一行分段切换"文件""改动"，⇧⌘E 这类打开某一页的操作会切回"文件"。"文件"页顶上是检索框，框里有字时下面是检索结果、没字时是文件树；有字时框里有清空按钮（和 Esc 一样）；大小写（Aa）、正则（.*）和筛选（漏斗，打开时下面展开包含、排除两个框）常驻在框里的右端，输入前就能设。点开检索结果不清空，清空才回到树；定位当前文件、⇧⌘E 会先清掉检索回到树。
  - 它挤窄标签栏和终端（编辑器），不浮在上面、点别处也不收起，和"图片 / 技能与工具"这些浮层面板分开。开关默认按项目记在 ui.json 的 `filesPanels`（键是项目 ID，同一项目的各工作区共用）；设置的「右侧文件栏开关」可改成所有项目共用（`filesPanelShared`、`filesPanelOn`），切换时当前项目的开关原样带过去。
  - 开关按钮照 Orca 固定在右上角：关着时在标签栏最右边，开着时在文件栏顶栏最右边，位置不变。打开、收起时文件栏从右边缘滑进滑出（200ms），切到开关不一样的项目时直接是那个项目的样子、不播动画（`snapPanels`，日志浮层也一样），终端只在打开开始、收起结束时改一次宽度，免得里面的程序跟着动画反复重排。宽度 `filesPanelWidth` 所有工作区共用，拖左边缘调宽（220–640），松手才写文件。
  - 文件树页的顶栏照 WebStorm 有两个按钮：准星是定位当前文件（检索时不显示；⌥F1，文件顶栏也有一个；展开上级目录、选中并滚到中间，当前文件是 diff、日志或在工作区外时置灰），两个相对的箭头是全部折叠（读过的目录不重读）。
  - 快捷键：⌘L 开关，⇧⌘E 文件树、⇧⌘G 改动（已经在那一页时关掉，⇧⌘E 在检索时改为回到树；编辑器有焦点时让给它的"查找上一个"），⇧⌘F 聚焦检索框（焦点在文件树上、选中的是目录时只搜这个目录），⌘K 提交（只在文件标签在前台或焦点在文件栏里时，终端里 ⌘K 是清屏）。
- 打开的文件照 Orca 是标签栏里的标签，排在终端标签后面（`docTabs`），带未保存的圆点。文件树里单击打开的是预览标签（斜体，`fileDoc.transient`），下一次单击换掉它；双击文件或标签、从别处打开（⌘P、检索、改动、链接）、改了内容都会常驻。`activeTerm[工作区]` 为 `filesTabID` 时选中的是文件（哪个看 `filesView.cur`），`currentTerminal` 返回 nil，终端断开接入。没有终端的工作区也能开。⌘P 打开随处搜索的"文件"页（`路径:行号` 跳行，不离开终端，选中后才切过来），⌘S 保存，⌘W 关当前文件，关掉最后一个就回到之前的终端。打开的文件、当前文件和展开的目录按工作区存在 ui.json 的 `files`。
- 随处搜索（`everywhere.go`，照 WebStorm 的双击 Shift）：一个弹框分"所有""文件""符号""操作""文本"五页，⇥ / ⇧⇥ 换页；⇧⌘P 打开在"所有"、⌘P 在"文件"、⇧⌘A 在"操作"。设置「快捷键」的文件一组里可以打开「双击 ⇧ 打开随处搜索」（默认关：用 ⇧ 切中英文的输入法会撞上），单独连按两下 ⇧ 打开"所有"页，中间按了别的键不算（mygo 的 `Context.DoubleTap`）。
  - 文件页按名称模糊匹配，查询为空时先列最近打开的文件（`filesView.recent`，最多 30 个，只在内存里）；「包括非项目条目」打开时在后台遍历整个工作区，被 git 忽略的也匹配（`files.ListAll`，node_modules 这类依赖目录照旧跳过），关弹框就放掉。底下一行是选中文件的完整路径。
  - 操作页列不依赖焦点的窗口级操作（`paletteActions`：新终端、新工作区、设置、侧栏、文件栏各页、Git 日志、推送、新分支等），名字和快捷键取自快捷键表，回车直接做；依赖焦点的（终端、编辑器里的键）不列，弹框关掉后焦点已经换了。
  - 文本页是全文检索（按字面、不分大小写，`syncQuickText`）：输入停顿 150ms 后在后台搜，按文件栏检索框限定的目录搜，攒够 50 条就停；每条左边是命中的那一行，右边是文件名和行号，回车跳到那一行并选中命中的字。底下"在文件栏中查看全部"把检索词交给文件栏的检索框（`searchText`，大小写、正则关掉，限定的目录照旧）。
  - 符号页按名字找声明（`files.FindSymbols`）：不建索引，每次现查，`git grep -i -F` 粗筛出含查询的行（边读边看，最多看 5 万行），再用跳到定义的声明写法认出名字里含查询的声明，只要带关键字或签名的（赋值、字段这类弱匹配不算），名字一样的最前、开头一样的其次，最多 200 条；按文件栏检索框限定的目录搜。每条是名字、种类和文件名:行号，回车跳到声明并选中名字。「只看类型」只留类、结构体、接口、枚举这类（WebStorm 的"类"页）。2 万个文件的仓库一次 0.2 秒左右，单个字母约 0.8 秒、临时分配 10 MB 左右，用完就放掉。
  - "所有"页文件、符号、操作、文本各取前 5 条，组标题右边"更多"换到那一页。
- 文件树里点一行就选中它（`treeSel`，之后当前文件换了就改回高亮当前文件），点过后焦点在文件树上。选中目录时按 ⇧⌘F，或在目录的右键菜单里点「在此目录中查找…」，检索只搜这个目录（`files.Query.Dir`）：检索框下面一行是"在 某目录 中"的标签，× 回到整个工作区，清空检索词时范围留着；限定的目录被 git 忽略时现列那个目录（`files.ListDir`，依赖目录也搜）。焦点在别处按 ⇧⌘F 搜整个工作区。
- Markdown 文件打开时默认是预览，顶栏的切换按钮（预览时是代码图标"查看源码"，源码时是眼睛图标"预览"）换到源码；从检索结果、`路径:行号` 跳到某一行时直接是源码。预览状态不记进 ui.json，重开窗口恢复的文件也是预览。
- 网页文件（`.html`、`.htm`、`.xhtml`）和 Markdown 一样默认是预览、顶栏切到源码（`htmlpreview.go`）：预览是不带工具栏的系统 WebKit 页面，第一次显示预览时建、关掉标签时销毁，经 `loadFileURL` 载入，页面能读文件所在目录和子目录里的样式、脚本、图片，上级目录读不到。只显示这个文件：页内锚点照常跳，点到别处的链接不在预览里跳走，网址在网页标签里打开、本地文件在文件标签里打开，mailto: 这类交给系统。文件在磁盘上变了（agent 重写报告）自动重新载入，⌘R、⇧⌘R 也能重新载入。要前进后退、手机预览或给 agent 操作，在网页标签里打开（终端链接卡片的「在 Posse 中打开」，或 `posse web open <路径>`）。
  - 预览的滚动位置跟着文档（`fileDoc.mdScroll`），切到别的标签、源码再回来接着看；跳到某一行后再切回预览从头开始；关掉标签、重开窗口不留。
  - 正文字号就是编辑器字号（默认 13），预览和源码在前台时 ⌘= ⌘- ⌘0 都调编辑器字号，版心最宽 820（默认字号下）、随字号等比放宽；排版照 GitHub 的 Markdown 样式，字号、行高和块间距见 `docs/design.md` 的「字号」。预览里的文字能拖选、⌘C 复制（整篇一个选区，和历史页的回复一样）。
  - 开头 `---` 围起来的 YAML 头部（agent 的记忆、技能常这样写）画成正文上面的属性列表：左边一列键（嵌套的键缩进）、右边是值，比正文小一号；只认键值、嵌套的键和列表项，认不出来的照普通 Markdown 显示。
  - 照 GitHub 解释正文里的 HTML（`markdown_html.go`；历史页、任务页不解释，agent 在回复里提到的标签照原文显示）：`align` 居中、靠右段落和标题，`<img>` 照写的 `width`、`height`（像素或百分比），`<a>` 包着的图片点了打开链接，`<br>`、`<b>`、`<kbd>`、`<small>`、`<sup>` 这类行内标签，`<table>` 的格子里能放标题、段落和图片（列宽照 `width`；格子里只有一段文字、第一行是 `<th>` 的照 Markdown 表格画），`<details>` 点 `<summary>` 展开收起，`<pre>`、列表、引用、分割线；注释不显示，`<script>`、`<style>`、表单这类连内容一起丢掉，认不出的标签只留里面的内容。`<td>` 和 `</td>` 之间空了行写的 Markdown 挂回所在的格子（CommonMark 的 HTML 块到空行就结束，要自己拼回去）。
  - 图片（Markdown 的 `![]()` 和 `<img>`，`mdimage.go`）后台载入、按地址缓存在打开的文档上，关掉标签就释放：相对路径按文档所在目录找，`/` 开头的找不到时按工作区根目录找（GitHub 上指仓库根目录），去掉 `?raw=true` 这类后缀；http(s) 的照 GitHub 下载（20 秒超时，最大 20 MB）；`data:` 地址直接解。位图超过约 400 万像素等比缩小，按原图尺寸排、最宽不超过版心。SVG 交给 mygo 画，它不画文字，带文字的 SVG（shields.io 的徽章）和载不了的图显示成说明文字的小块。
  - `[[名字]]`、`[[名字|显示的字]]`（Obsidian 和 agent 记忆互相引用的写法）画成强调色链接，点了在文件标签里打开同一目录下的 `名字.md`（写了扩展名的照写的找），找不到时错误条报出来；历史页的回复里只上色、点不了。
  - 语言写 `mermaid` 的代码块画成图（和历史页的回复共用，`internal/mermaid`）：后台画，画好之前照代码块显示；颜色跟着深浅主题，节点是中性的次级填充；按原始大小居中，比正文宽就等比缩小；悬停时右上角的按钮多一个源码和图的切换（按源码记，不存），复制的是源码；写错的照代码块显示，上面一行红字报错。图里的文字不能选、⌘F 搜不到，切到源码才行。
  - 表格（和历史页的回复共用）比正文宽时长句折行，还放不下就整张左右滚；代码块不折行，长行放不下时左右滚，目录树、对齐的注释保持成列。
  - 预览和 Annotate 里 ⌘F 打开和编辑器一样的查找栏（`docfind.go`，不分大小写，按键跟着设置里编辑器的查找）：右上角显示第几个 / 共几个，回车、⌘G 下一个，⇧回车、⇧⌘G 上一个（查找栏开着时 ⇧⌘G 不去开关改动页），Esc 关闭；命中铺底色，当前那个深一点并滚进视野。
- 图片（`imageview.go`）按原分辨率解码（超过约 2500 万像素才等比缩小；原图超过 1600 万像素的缩小用面积平均，`media.DecodeLargePreviewBytes`，内存只多出「解出来的原图 + 目标位图」，CatmullRom 的中间缓冲要上 GB）。原图超过 5000 万像素、或任一边超过 5 万像素的不解码，写明尺寸、不在这里预览（解码先按原尺寸整张解出来；面积平均的累加器和目标宽成正比），可以用默认应用打开；解完大图、关掉它的标签后马上把内存还给系统。画在自绘的视口里：打开时适应窗口（整张放得下，比窗口小的按原大，原大是图片一个像素对屏幕一个物理像素），⌘ 加滚动以指针处为中心缩放，⌘= ⌘- 放大缩小、⌘0 回到适应窗口（图片标签在前台时这三个键给图片，不改字号），双击在适应窗口和原大之间切换、指针下那一点不动；比视口大时滚动或拖动平移，拖不出边界，比视口小的方向居中。放大超过原大时按像素块画。顶栏写尺寸、格式和文件大小；有透明像素的图透明处铺棋盘格，顶栏的开关关掉（所有图片共用，ui.json 的 `imageCheckerOff`）；缩放比例点开选适应窗口、100%、200%、放大、缩小。缩放和位置不记，关了再开回到适应窗口；触控板捏合不支持（mygo 不转发这个手势）。Go 解不开、浏览器和预览能显示的不合规图片（比如带 tRNS 的 RGBA PNG）退回系统的 ImageIO 解码（`media.decodeAny`）。
- 动图（GIF、APNG、动画 WebP，`anim.go`）经 ImageIO 逐帧取合成好的画面（`media.OpenAnim`；PNG 先看文件头有没有 acTL，没有的不交给 ImageIO），每帧最多约 400 万像素；顶栏多写帧数、一遍的时长和播放/暂停按钮，按文件里的循环次数放完停在最后一帧，再点播放从头放。帧合计不超过 32 MB 时在后台全部解出来留着，超过就边放边解、只留两帧。换帧只重画不重建视图；标签切走、窗口被挡住时不画，回来后从当前帧接着放、不追赶。帧时长照浏览器，不超过 10ms 的按 100ms。
- 跳到定义：编辑器里 ⌘点击、F12 或右键"跳到定义"。照 Zed 先看指针下是什么：网址交给浏览器（遇到全角标点就结束，结尾的英文句末标点不算）；引号里（或 `#include <>` 里）含 `/` 或 `.` 的当文件路径；注释里和 Markdown、JSON 这类非代码文件里只认路径和网址；都不是才当标识符。按住 ⌘ 时指针下的这一段加下划线、指针变手形。
  - 路径按 import 的规则解析后直接打开，找不到提示：`./`、`../` 相对当前文件，`~/`、`@/` 这类别名按 tsconfig、jsconfig 的 `paths` 和 `baseUrl`，Go 的 import 路径按 go.mod 找到本地目录、模块缓存或标准库；没有扩展名补 .ts/.js/.vue 等，目录找 index.*；`lodash`、`@scope/pkg` 这类第三方包从 node_modules 开入口；`:行号` 后缀跳行。
  - 标识符照 ctags 的思路，没有语法树和类型信息：在工作区的源码文件（Go、Java/Kotlin/Swift/Dart/C#、JS/TS、Python、Ruby、Rust、C/C++、PHP、Lua、Shell）里按各语言的声明写法找同名定义，名字落在注释或字符串里的不算；`a.b` 会先找 `a` 指向的文件或类型（变量就往上找它的类型），当前文件 import 的、同目录、同类语言的排前面。明确只有一处就直接跳过去并选中名字；几处同名的弹出列表（路径:行号和那一行的代码，↑↓ 回车或点击）；一处都没有在编辑器顶上提示。光标所在的那一行本身是定义时先把它排除，别处一处都没有就改为找用法（文件栏的检索框按整词搜）。有未保存改动的文件搜编辑器里的内容；查找期间编辑器顶上显示"正在查找"。
  - 跳转历史：⌘P、检索结果、链接卡片、改动列表、跳到定义打开文件都记下（最多 50 个），⌃- 依次回去、⌃⇧- 再往前（⌘[ 是编辑器的减少缩进）。
- 编辑区是 mygo 的 `ui/editor`（行号、高亮、⌘F 查找替换都是它的）。超过 5 MB 只读，超过 50 MB 或二进制不读内容。.json 文件的顶栏有"格式化"按钮（花括号图标，⇧⌥F，`jsonfmt.go`）：按文件原来的缩进（制表符、2 或 4 个空格，看不出来用 2 个）重排，键的顺序不变，结尾换行照原样；作为一次编辑，⌘Z 能撤销，保存照常按 ⌘S；语法错误时编辑器顶上提示第几行，不改内容。
- 磁盘同步：文件栏或文件标签看得见时每秒 stat 一次展开的目录和打开的文件，磁盘戳带 inode，"写临时文件再改名"的保存也认得出。工作区目录打开时不在、后来又出现的，下一次轮询读出来。磁盘上变了：没有未保存的改动就重载，有就显示冲突横幅；文件没了标出已删除。
- 保存在同一目录写临时文件再改名，保留权限位，符号链接写到它指向的文件；保存前磁盘戳和打开时不一样就先问。有未保存的文件时 `Window.OnClose` 拦住关窗口和退出（退出会先关窗口）。
- 文件图标（`fileicons.go` 的表，照 WebStorm 新界面）：TS、JS、GO 字母，代码、Shell、标记、样式、配置、Markdown、图片、音视频、表格、数据库、压缩包、PDF、锁文件、Git、Docker 各一个图形；移动端和前端工程另认 Dart、Flutter（`pubspec.yaml` 等）、Swift、Kotlin、Java、Vue、Android（`AndroidManifest.xml`、apk）、Gradle、storyboard/xib、C 头文件（h）和 Objective-C（m）、签名证书和密钥库；完整文件名先于扩展名（`package-lock.json`、`go.sum` 是锁文件）。Xcode 的包目录（`.xcodeproj`、`.xcworkspace`、`.xcassets`、图标集、图片集、`.lproj`、framework）在文件树里也换成各自的图标，并起来的目录行按最后一段认，其余目录是文件夹。文件树、文件标签、快速打开、检索结果、跳到定义的列表、Git 的文件列表、提交日志的按文件筛选都用它；手机文件页的文件树和搜索结果用同一套（见 `mobile.md`）。颜色规则见 `docs/design.md` 的「图标」。
- 文件树和检索结果的右键菜单：复制路径、复制相对路径，在访达中显示、用默认应用打开，git 仓库里的文件多了文件历史和 Annotate，最后是"删除…"（`askTrashPath`）：确认后移到废纸篓（能找回，跟不跟踪都一样），打开着的、没改过的文件跟着关掉，改过的留着显示已删除。
- 文件树里的符号链接用带拐弯箭头的文件夹、文件图标（指向目录的照样能展开），悬停显示指向的路径；git 把链接当文件记，指向目录的链接按文件查是否被忽略。
- 文件名照 WebStorm 按 git 状态上色（和改动页同一套颜色，见 `git.md`）：修改蓝、新增绿、未加入 Git 和冲突红，悬停文件名说明状态；含改动的目录（包括只删了文件的）标蓝。颜色来自改动页同一份 git 状态，文件内容看得见时轮询。
- 变暗（被 gitignore 忽略）、快速打开、检索共用一份 `git ls-files -co --exclude-standard` 的清单（不是 git 仓库时遍历目录，跳过 node_modules 等），超过 10 秒就重列，文件栏和文件标签都看不见时放掉。检索在后台逐个读清单里的文件，每次检索带编号、旧的结果丢掉，有未保存改动的文件搜编辑器里的内容，最多 2000 条命中。
