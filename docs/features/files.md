# 文件

文件栏和文件标签（窗口进程，不经过常驻进程）。

- 文件：照 Orca 分两处，全部在窗口进程里，不经过常驻进程。
  - 文件栏（`filespanel.go`）停靠在主区域最右边，顶栏是"历史""文件"两个图标页签（时钟、文件，`panelTab`）（选哪个记在 ui.json 的 `filesPanelHistory`，所有项目共用）：历史是当前项目（项目目录和它的各个 worktree）最近的会话，点一个跳到历史页打开、悬停时右上角点播放接着聊、右下角点删除移到废纸篓（和历史页的"移到废纸篓"同一套确认，正在终端里运行的不让删，`trashListedSession`；`recentList`，开着时每 15 秒刷新）；文件下面一行分段切换文件树、检索、改动，⇧⌘E 这类打开某一页的操作会切回"文件"；它挤窄标签栏和终端（编辑器），不浮在上面、点别处也不收起，和"图片 / 技能与工具"这些浮层面板分开（旧版的历史浮层 `rightPanel: history` 读进来改成文件栏的历史页）（开关按项目记在 ui.json 的 `filesPanels`，键是项目 ID：在 A 项目打开，切到 B 项目不跟着打开，同一项目的各工作区共用；旧版不分项目的 `filesPanel` 和更早的 `rightPanel: files` 读进来记到当前项目上）。开关按钮照 Orca 固定在右上角：关着时在标签栏最右边，开着时在文件栏顶栏最右边，位置不变。点开关打开、收起时文件栏从右边缘滑进滑出（200ms），切到开关不一样的项目时直接是那个项目的样子、不播动画（`snapPanels`，日志浮层也一样），终端只在打开开始、收起结束时改一次宽度，免得里面的程序跟着动画反复重排。宽度存在 `filesPanelWidth`，所有工作区共用；拖左边缘调宽（220–640），松手才写文件。快捷键：⌘L 开关，⇧⌘E 文件树、⇧⌘G 改动（已经在那一页时关掉；编辑器有焦点时让给它的"查找上一个"），⇧⌘F 检索，⌘K 提交（只在文件标签在前台或焦点在文件栏里时，终端里 ⌘K 是清屏）。
  - 打开的文件照 Orca 是标签栏里的标签，排在终端标签后面（`docTabs`），带未保存的圆点。文件树里单击打开的是预览标签（斜体，`fileDoc.transient`），下一次单击换掉它；双击文件或标签、从别处打开（⌘P、检索、改动、链接）、改了内容都会常驻。`activeTerm[工作区]` 为 `filesTabID` 时选中的是文件（哪个看 `filesView.cur`），`currentTerminal` 返回 nil，终端断开接入。没有终端的工作区也能开。⌘P 快速打开（`路径:行号` 跳行，不离开终端，选中后才切过来），⌘S 保存，⌘W 关当前文件，关掉最后一个就回到之前的终端。
  - Markdown 文件打开时默认是预览，顶栏的切换按钮换到源码；从检索结果、`路径:行号` 跳到某一行时直接是源码。预览状态不记进 ui.json，重开窗口恢复的文件也是预览。预览里的文字能拖选、⌘C 复制（整篇一个选区，和历史页的回复一样）。表格（历史页的回复共用，`markdown.go` 的 `table`）比正文宽时：先量出每列不折行的宽度和最长的拆不开的词（`measure`，按空格和每个汉字拆开，一张表量一次存在块上），放得下按内容宽；长句折行能放下的按各列能收缩的余地分掉差额、刚好铺满正文宽；连拆不开的词（代码）都放不下的，长句的列最宽 360、短的按内容，整张左右滚，滚动条画在表格下面。横向滚动容器给内容的宽度没有上限，所以列宽要自己算，不能交给表格按内容收缩。
  - 图片（`imageview.go`）按原分辨率解码（超过 2400 万像素才等比缩小，`media.DecodePreview`），画在自绘的视口里：打开时适应窗口（整张放得下，比窗口小的按原大，原大是图片一个像素对屏幕一个物理像素），⌘ 加滚动以指针处为中心缩放，⌘= ⌘- 放大缩小、⌘0 回到适应窗口（图片标签在前台时这三个键给图片，不改字号），双击在适应窗口和原大之间切换、指针下那一点不动；比视口大时滚动或拖动平移，拖不出边界，比视口小的方向居中。放大超过原大时按像素块画。顶栏写尺寸、格式和文件大小；有透明像素的图透明处铺棋盘格，顶栏的开关关掉（所有图片共用，记在 ui.json 的 `imageCheckerOff`）；缩放比例点开选适应窗口、100%、200%、放大、缩小。缩放和位置不记，关了再开回到适应窗口；触控板捏合不支持（mygo 不转发这个手势）。
  - 跳到定义（`definition.go`，`internal/files/symbols.go`、`links.go`）：编辑器里 ⌘点击、F12 或右键"跳到定义"。照 Zed 的 hover_links 先看指针下是什么（`files.LinkAt`）：网址交给浏览器；引号里（或 `#include <>` 里）含 `/` 或 `.` 的当文件路径，别的字符串不算、字符串里也不认标识符；注释里（行首的 `//`、`#`、`*`、`--`，或前面有 `//`）只认路径（不带引号也行，按空白分词、去掉两头的标点）和网址，不认标识符；Markdown、JSON 这类不认识语言的文件里也只认路径和网址（`IsCode`）。路径按 import 的规则解析（`ResolveImport`：`./`、`../` 相对当前文件，绝对路径照原样，`~/`、`@/` 这类别名按 tsconfig、jsconfig 的 `paths` 和 `baseUrl`、没有就试 `src/` 和根目录，Go 的 import 路径按 go.mod 的 module 名换成目录、取里面第一个 .go 文件；没有扩展名补 .ts/.js/.vue 等，目录找 index.*；`:行号` 后缀跳行；第三方包：`lodash`、`@scope/pkg/sub` 从当前目录往上找 node_modules，按 package.json 的 types、typings、module、main 开入口；Go 的 import 路径按 go.mod 的 replace 到本地路径、require 到 `GOMODCACHE/模块@版本`，都不是的当标准库到 `GOROOT/src`）直接打开，找不到提示；都不是才当标识符：取它和前面的限定符（`a.b` 里的 `a`，`WordAt`），先解析当前文件的 import（`files.Imports`：JS/TS 的 import、require、export from，Python 的 from/import，Go 的 import 块和别名，Java/Kotlin 的 import 按类路径在清单里找文件，Dart 的 package: 按 lib/，C 的 #include；只看单行写法），import 这个名字（或限定符是 import 的别名）的文件 +8 优先，这个文件 import 的别的文件 +5；粗筛含这个词的行时 git 仓库用 `git grep -w --untracked`（毫秒级、自动按 gitignore），不是 git 仓库或 git 失败才在 Go 里逐个读文件（`grepLines`）；名字落在注释或字符串里的行不算定义；有带声明的结果时别的文件里的弱匹配（赋值、字段、对象字面量的键）不列，在工作区清单里认识的源码文件（`familyOf`：Go、Java/Kotlin/Swift/Dart/C#、JS/TS、Python、Ruby、Rust、C/C++、PHP、Lua、Shell）中对含这个词的行按各语言声明的写法试正则（`patternsFor`：带关键字的声明 3 分、方法签名 2 分、赋值和字段 1 分；`return foo(` 这类前面带关键字的不算签名），再按位置加分：限定符指向的文件（文件名或 Go 包目录名等于限定符、或里面有它的类型声明）+6，光标所在文件 +4、同目录 +2、同类语言 +1，测试文件 −1。没有语法树和类型信息，是照 ctags 的思路。只有一处、或带声明的只有一处（`files.Unique`）就直接跳过去并选中名字；几处同名的弹出列表（路径:行号和那一行的代码，↑↓ 回车或点击），一处都没有在编辑器顶上提示一下（`fadeHint`）。光标所在的那一行本身是定义时照 Zed 先把它排除：别处还有一处就跳过去，一处都没有退化为找用法（文件栏切到检索页按整词搜）。有未保存改动的文件搜编辑器里的内容。限定符是变量时先在这个文件里往上找它的类型（`files.TypeOf`：`new Foo(`、`x: Foo`、`Foo x =`、Go 的 `NewFoo(`、`&Foo{}`，取光标上方最近的一处，大写开头的不推断），再按类型找方法。跳转历史在 `openDoc` 里统一记（`filesView.jumps`，最多 50 个）：⌘P、检索结果、链接卡片、改动列表、跳到定义打开文件都算，⌃- 依次回去、⌃⇧- 再往前（`forward`，新的跳转清掉它；⌘[ 是编辑器的减少缩进）。查找期间编辑器顶上显示"正在查找"；文件清单复用快速打开和检索的那份。按住 ⌘ 时指针下的这一段（路径、网址或标识符）加下划线、指针变手形（改在 `third_party/mygo` 的编辑器里，`State.LinkAt`）。
  - 编辑区是 mygo 的 `ui/editor`（行号、高亮、⌘F 查找替换都是它的）。未保存判断用 `editor.Buffer.Modified`，按缓冲区版本缓存；不能拿版本号判断，撤销也会让版本号加一。超过 5 MB 只读，超过 50 MB 或二进制不读内容。
  - 不用 fsnotify：macOS 上它基于 kqueue，监听一个目录要为其中每个文件各开一个描述符。改为文件栏或文件标签看得见时每秒 stat 一次展开的目录和打开的文件，磁盘戳带 inode，"写临时文件再改名"的保存也认得出。磁盘上变了：没有未保存的改动就重载，有就显示冲突横幅；文件没了标出已删除。
  - 保存在同一目录写临时文件再改名，保留权限位，符号链接写到它指向的文件；保存前磁盘戳和打开时不一样就先问，不默默覆盖 agent 的修改。有未保存的文件时 `Window.OnClose` 拦住关窗口和退出（退出会先关窗口）。
  - 变暗（被 gitignore 忽略）、快速打开、检索共用一份 `git ls-files -co --exclude-standard` 的清单（不是 git 仓库时遍历目录，跳过 node_modules 等），超过 10 秒就重列，文件栏和文件标签都看不见时放掉。检索在后台逐个读清单里的文件，每次检索带编号、旧的结果丢掉，有未保存改动的文件搜编辑器里的内容，最多 2000 行。
  - 打开的文件、当前文件和展开的目录按工作区存在 ui.json 的 `files`；`saveState` 把它深拷贝后交给写文件的协程。后台读文件的结果经 `a.update` 交回界面线程，测试里没有窗口时排到下一帧开头执行。
