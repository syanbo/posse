# 文件

文件栏和文件标签，全部在窗口进程里，不经过常驻进程。

- 文件：照 Orca 分两处。
  - 文件栏（`filespanel.go`）停靠在主区域最右边，顶栏是"历史""文件"两个图标页签（时钟、文件，`panelTab`）（选哪个记在 ui.json 的 `filesPanelHistory`，所有项目共用）：历史是当前项目（项目目录和它的各个 worktree）最近的会话，点一个跳到历史页打开、悬停时右上角点播放接着聊、右下角点删除移到废纸篓（和历史页的"移到废纸篓"同一套确认，正在终端里运行的不让删，`trashListedSession`；`recentList`，开着时每 15 秒刷新）；文件下面一行分段切换文件树、检索、改动，⇧⌘E 这类打开某一页的操作会切回"文件"；它挤窄标签栏和终端（编辑器），不浮在上面、点别处也不收起，和"图片 / 技能与工具"这些浮层面板分开（开关默认按项目记在 ui.json 的 `filesPanels`，键是项目 ID，同一项目的各工作区共用；设置的「右侧文件栏开关」可改成所有项目共用，记在 `filesPanelShared`、`filesPanelOn`，切换时当前项目的开关原样带过去）。开关按钮照 Orca 固定在右上角：关着时在标签栏最右边，开着时在文件栏顶栏最右边，位置不变。点开关打开、收起时文件栏从右边缘滑进滑出（200ms），切到开关不一样的项目时直接是那个项目的样子、不播动画（`snapPanels`，日志浮层也一样），终端只在打开开始、收起结束时改一次宽度，免得里面的程序跟着动画反复重排。宽度存在 `filesPanelWidth`，所有工作区共用；拖左边缘调宽（220–640），松手才写文件。文件树页的顶栏照 WebStorm 有两个按钮：准星是定位当前文件（⌥F1，文件顶栏也有一个；展开上级目录、选中并滚到中间，当前文件是 diff、日志或在工作区外时置灰），两个相对的箭头是全部折叠（读过的目录不重读）。快捷键：⌘L 开关，⇧⌘E 文件树、⇧⌘G 改动（已经在那一页时关掉；编辑器有焦点时让给它的"查找上一个"），⇧⌘F 检索，⌘K 提交（只在文件标签在前台或焦点在文件栏里时，终端里 ⌘K 是清屏）。
  - 打开的文件照 Orca 是标签栏里的标签，排在终端标签后面（`docTabs`），带未保存的圆点。文件树里单击打开的是预览标签（斜体，`fileDoc.transient`），下一次单击换掉它；双击文件或标签、从别处打开（⌘P、检索、改动、链接）、改了内容都会常驻。`activeTerm[工作区]` 为 `filesTabID` 时选中的是文件（哪个看 `filesView.cur`），`currentTerminal` 返回 nil，终端断开接入。没有终端的工作区也能开。⌘P 快速打开（`路径:行号` 跳行，不离开终端，选中后才切过来），⌘S 保存，⌘W 关当前文件，关掉最后一个就回到之前的终端。
  - Markdown 文件打开时默认是预览，顶栏的切换按钮（预览时是代码图标"查看源码"，源码时是眼睛图标"预览"）换到源码；从检索结果、`路径:行号` 跳到某一行时直接是源码。预览状态不记进 ui.json，重开窗口恢复的文件也是预览。预览里的文字能拖选、⌘C 复制（整篇一个选区，和历史页的回复一样）。语言写 `mermaid` 的代码块画成图（和历史页的回复共用，`internal/mermaid`）：后台画，画好之前照代码块显示；颜色跟着深浅主题，节点是中性的次级填充；按原始大小居中，比正文宽就等比缩小；语言栏多一个源码和图的切换（按源码记，不存），复制的是源码；写错的照代码块显示，上面一行红字报错。图里的文字不能选、⌘F 搜不到，切到源码才行。表格（和历史页的回复共用）比正文宽时长句折行，还放不下就整张左右滚。预览和 Annotate 里 ⌘F 打开和编辑器一样的查找栏（`docfind.go`，不分大小写，按键跟着设置里编辑器的查找）：右上角显示第几个 / 共几个，回车、⌘G 下一个，⇧回车、⇧⌘G 上一个（查找栏开着时 ⇧⌘G 不去开关改动页），Esc 关闭；命中铺底色，当前那个深一点并滚进视野。
  - 图片（`imageview.go`）按原分辨率解码（超过约 2500 万像素才等比缩小，`media.DecodePreview`），画在自绘的视口里：打开时适应窗口（整张放得下，比窗口小的按原大，原大是图片一个像素对屏幕一个物理像素），⌘ 加滚动以指针处为中心缩放，⌘= ⌘- 放大缩小、⌘0 回到适应窗口（图片标签在前台时这三个键给图片，不改字号），双击在适应窗口和原大之间切换、指针下那一点不动；比视口大时滚动或拖动平移，拖不出边界，比视口小的方向居中。放大超过原大时按像素块画。顶栏写尺寸、格式和文件大小；有透明像素的图透明处铺棋盘格，顶栏的开关关掉（所有图片共用，记在 ui.json 的 `imageCheckerOff`）；缩放比例点开选适应窗口、100%、200%、放大、缩小。缩放和位置不记，关了再开回到适应窗口；触控板捏合不支持（mygo 不转发这个手势）。Go 解不开、浏览器和预览能显示的不合规图片（比如带 tRNS 的 RGBA PNG）退回系统的 ImageIO 解码（`media.decodeAny`）。
  - 动图（GIF、APNG、动画 WebP，`anim.go`）经 ImageIO 逐帧取合成好的画面（`media.OpenAnim`；PNG 先看文件头有没有 acTL，没有的不交给 ImageIO），每帧最多约 400 万像素；顶栏多写帧数、一遍的时长和播放/暂停按钮，按文件里的循环次数放完停在最后一帧，再点播放从头放。帧合计不超过 32 MB 时在后台全部解出来留着，超过就边放边解、只留两帧。换帧在 Draw 里按时间算、用 `Painter.After` 约下一次，只重画不重建视图；标签切走、窗口被挡住时不画也不约，回来后从当前帧接着放、不追赶。帧时长照浏览器，不超过 10ms 的按 100ms。
  - 跳到定义：编辑器里 ⌘点击、F12 或右键"跳到定义"。照 Zed 先看指针下是什么：网址交给浏览器（遇到全角标点就结束，结尾的英文句末标点不算）；引号里（或 `#include <>` 里）含 `/` 或 `.` 的当文件路径；注释里和 Markdown、JSON 这类非代码文件里只认路径和网址；都不是才当标识符。按住 ⌘ 时指针下的这一段加下划线、指针变手形。
    - 路径按 import 的规则解析后直接打开，找不到提示：`./`、`../` 相对当前文件，`~/`、`@/` 这类别名按 tsconfig、jsconfig 的 `paths` 和 `baseUrl`，Go 的 import 路径按 go.mod 找到本地目录、模块缓存或标准库；没有扩展名补 .ts/.js/.vue 等，目录找 index.*；`lodash`、`@scope/pkg` 这类第三方包从 node_modules 开入口；`:行号` 后缀跳行。
    - 标识符照 ctags 的思路，没有语法树和类型信息：在工作区的源码文件（Go、Java/Kotlin/Swift/Dart/C#、JS/TS、Python、Ruby、Rust、C/C++、PHP、Lua、Shell）里按各语言的声明写法找同名定义，名字落在注释或字符串里的不算；`a.b` 会先找 `a` 指向的文件或类型（变量就往上找它的类型），当前文件 import 的、同目录、同类语言的排前面。明确只有一处就直接跳过去并选中名字；几处同名的弹出列表（路径:行号和那一行的代码，↑↓ 回车或点击）；一处都没有在编辑器顶上提示。光标所在的那一行本身是定义时先把它排除，别处一处都没有就改为找用法（文件栏切到检索页按整词搜）。有未保存改动的文件搜编辑器里的内容；查找期间编辑器顶上显示"正在查找"。
    - 跳转历史：⌘P、检索结果、链接卡片、改动列表、跳到定义打开文件都记下（最多 50 个），⌃- 依次回去、⌃⇧- 再往前（⌘[ 是编辑器的减少缩进）。
  - 编辑区是 mygo 的 `ui/editor`（行号、高亮、⌘F 查找替换都是它的）。超过 5 MB 只读，超过 50 MB 或二进制不读内容。.json 文件的顶栏有"格式化"按钮（花括号图标，⇧⌥F，`jsonfmt.go`）：按文件原来的缩进（制表符、2 或 4 个空格，看不出来用 2 个）重排，键的顺序不变，结尾换行照原样；作为一次编辑，⌘Z 能撤销，保存照常按 ⌘S；语法错误时编辑器顶上提示第几行，不改内容。
  - 文件栏或文件标签看得见时每秒 stat 一次展开的目录和打开的文件，磁盘戳带 inode，"写临时文件再改名"的保存也认得出。工作区目录打开时不在、后来又出现的，下一次轮询读出来。磁盘上变了：没有未保存的改动就重载，有就显示冲突横幅；文件没了标出已删除。
  - 保存在同一目录写临时文件再改名，保留权限位，符号链接写到它指向的文件；保存前磁盘戳和打开时不一样就先问，不默默覆盖 agent 的修改。有未保存的文件时 `Window.OnClose` 拦住关窗口和退出（退出会先关窗口）。
  - 文件树里的符号链接用带拐弯箭头的文件夹、文件图标（指向目录的照样能展开），悬停显示指向的路径；git 把链接当文件记，指向目录的链接按文件查是否被忽略。
  - 文件名照 WebStorm 按 git 状态上色（和改动页、提交里的文件同一套颜色，见 git.md）：修改蓝、新增绿、未加入 Git 和冲突红，悬停文件名说明状态；含改动的目录（包括只删了文件的）标蓝。颜色来自改动页同一份 git 状态，文件内容看得见时轮询。
  - 变暗（被 gitignore 忽略）、快速打开、检索共用一份 `git ls-files -co --exclude-standard` 的清单（不是 git 仓库时遍历目录，跳过 node_modules 等），超过 10 秒就重列，文件栏和文件标签都看不见时放掉。检索在后台逐个读清单里的文件，每次检索带编号、旧的结果丢掉，有未保存改动的文件搜编辑器里的内容，最多 2000 行。
  - 打开的文件、当前文件和展开的目录按工作区存在 ui.json 的 `files`。
