# SSH 远程工作区

目前完成连接基础：保存多台 Mac、SSH 认证、发现远端 Posse、Unix socket 转发和实际 daemon 的能力检查。窗口主机切换、接管、远端文件和 Git 尚未接入，当前不能用这些命令操作完整远程工作区。

## 配置与诊断

两端需安装带 `remote probe` 的 Posse。目标 Mac 开启系统「远程登录」，先在目标 Mac 正常打开 Posse，完成项目目录授权。

```sh
posse remote add office office-mac
posse remote add studio user@studio.local --port 22 --home '~/.posse' --executable '/Applications/Posse.app/Contents/MacOS/Posse'
posse remote list
posse remote check office
```

目标可以是 `~/.ssh/config` 的 Host 别名，沿用系统 OpenSSH 的 IdentityFile、ssh-agent、Keychain、known_hosts 和 ProxyJump。Posse 默认不转发 ssh-agent，不执行配置中的额外 LocalForward/RemoteForward 或 LocalCommand。未知主机显示 SSH 的指纹确认，主机密钥变化直接失败；密码和私钥口令仅经过本次连接的私有认证通道，不写入配置或日志。

`remote check` 默认不启动远端 daemon。加 `--start` 才通过目标 Posse 自己的启动流程拉起；不会安装、升级或交接远端程序。`--batch` 禁止认证提示，适合已有密钥认证和信任记录的检查。Ctrl-C 取消建连。

诊断结果来自隧道内的 `daemon.info`，包含实际运行的版本、构建、home、实例 ID 和已实现的能力；CLI 版本不会代替 daemon 能力。当前仅宣布 `rpc.v1` 和 `terminal.stream.v1`，不宣布尚未实现的接管、文件和 Git 服务。旧 daemon 不认识 `daemon.info` 时提示检查转发和更新远端。

检查结束关闭本次 SSH master，不停止远端 daemon 或终端。每次连接使用 Posse 自己的私有目录、control socket 和转发 socket，不复用或关闭用户其他工具的 master。一个连接内的发现命令、普通 RPC 和二进制流复用同一 SSH master。

窗口用的连接管理器已实现，尚未接到窗口入口：切主机或离开时取消正在进行的认证和建连，迟到的成功连接会被关闭；已连接的 master 最多保留三台空闲主机，每台五分钟后回收。复用要求保存的主机配置一致，并重新查询实际 daemon 的 home 和所需能力；复用失败不会自行发起新的认证。主动断开、master 退出和最终关闭会回收自有进程与私有目录，不停止目标 daemon。缓存仅保留传输，不恢复桌面控制权。

窗口认证弹窗使用独立队列，已由连接协调器调用，主机选择入口尚未开放：密码及私钥口令用遮蔽输入，保留原始空格和空值；主机密钥确认默认聚焦取消，明确点击「信任并连接」才接受。安全密钥触摸通知不要求填写答案，SSH 结束该通知时自动移除对应提示，不关闭后来排队的提示。用户取消会取消整次建连，切换显示的主机及窗口最终退出也会结束等待；被未保存文档拦住的退出不提前关闭认证。弹窗标明所连接的主机，回答不进入 UI 状态文件。

窗口连接协调器已把传输、认证和 `desktop.status` 握手串在一起：成功只建立查看身份，切换立即取消旧尝试并保留视图数据，迟到的握手不能恢复旧主机。轮询先保活桌面身份，失败或 SSH 退出会独立更新断线状态，断线后不重放写操作。主动断开先等待有限时的控制权释放，再回收对应传输；期间同一主机已重连时，旧清理不关闭新连接。窗口真正退出时取消轮询、认证和在途建连，收拢释放请求后关闭连接池；本机 daemon 启动等待也可取消，已经启动的 daemon 独立运行。目前 `Run` 创建了协调器，主机选择入口、本机控制身份和自动重连仍待接入，不能从这些内部接线操作完整远程工作区。

主机配置存于本机 `$POSSE_HOME/hosts.json`，权限 0600；每项有稳定 ID。用 `remote add ... --id <ID>` 更新现有项；`remote rm <名称或ID>` 仅忘记配置，不删除远端数据。重名时用 ID。配置可指定用户名、端口、远端 home 和可执行文件，路径必须绝对或以 `~/` 开头。

未指定程序路径时依次寻找目标 home 的 `bin/posse`、系统和用户 Applications 下的 Posse.app，以及 Homebrew 常用位置。目标 home 默认 `~/.posse`。发现输出使用独立标记行，允许 shell 启动时有其他输出。远端 socket 当前要求绝对路径、不超过 100 字节，且不含冒号、方括号、百分号、反斜杠或美元符号，避免 OpenSSH 转发语法改变路径。目标 home 在远端解析符号链接后参与身份核对。

## 桌面控制基础（尚未接入窗口）

`desktop.status/take/heartbeat/release` 提供当前 daemon 内的控制会话。接管携带实例 ID 和预期代次，成功后换代；心跳租期为 15 秒，释放或过期使旧身份失效。本机初次自动申请仅在无人控制时成功，显式接管才替换已有控制者。

带桌面身份的 `terminal.attach` 根据控制状态选择读写或查看。查看只接已有 live 终端，不启动待恢复记录、不改 PTY 尺寸、不交出内核的查询应答权；输入帧和尺寸帧在服务端丢弃。PTY 尺寸变化时查看流断开，重新接入取得对应网格的快照；手机原有 Watch 不受影响。桌面输入写入期限为 250 毫秒，写满或取消后断开当前输入连接，不重放未确认的按键，也不更改手机/CLI 写入的期限。接管、释放和租期过期会关闭旧控制订阅，使旧按键、尺寸和查询回复不能继续写入。无身份的旧版窗口在有人控制时拒绝接入；CLI 和手机的独立操作入口保持现有语义。

终端插件在首份快照前读取连接的实际网格与查看状态，快照到齐前丢弃输入，整帧回放期间禁止窗口改网格。查看端按远端网格显示，小窗口缩小字号以显示完整屏幕，窗口尺寸变化不重排快照；保留选择、复制与本地滚动，程序开启鼠标跟踪时也能直接选字。键鼠输入、自动查询应答、焦点报告、粘贴和程序剪贴板请求均受插件门禁约束，粘贴不会触发应用的图片回调。普通终端视图从固定请求的 Client 接入，控制身份变化后不按相同终端 ID 复用旧视图；重建当前终端时保留查找词，迟到的退出回调不能清掉新订阅。技能命令从确认时起固定创建与接入身份，切主机或失去身份只释放其显示连接并撤掉隐藏标记，已经接受的命令回到普通终端列表继续运行。窗口的连接生命周期、接管入口和完整自绘菜单门禁仍待下一步接入。

已接受的终端恢复不会因控制转移而取消，但恢复完成前 handoff 返回 `busy`；接过来的 daemon 取得 home 锁前也不接受新的恢复。窗口自动升级遇到 `busy` 延迟五秒再尝试，其他失败仍不自动重复；手动更新遇到忙碌时保留提示，由用户稍后重试。远程 Client 不会在隧道中断时本地创建 home 或启动 daemon，也不会用本机程序路径升级远端。

普通桌面请求经 `desktop.call` 携带固定实例、客户端与控制代次。项目/工作区创建、修改和删除，以及终端、任务和历史恢复等已登记的写入口，在服务端同一把控制锁内接受；迟到的旧身份拒绝。接受后由 daemon 持有，断开请求连接和换控制端不会撤销它；完成前阻止 handoff，正常停止先取消并等待这些操作，再关闭终端和存储。CLI 与 hooks 的独立入口不借用桌面身份。

写请求带窗口进程内递增的序号；同一身份、序号和参数取得已有结果，参数不同则拒绝。参数比较忽略 JSON 排版空白，保留字段顺序，避免结构体解码的大小写别名覆盖被误判为同一次操作。`desktop.operation` 查询指定请求，`desktop.operations` 列出当前实例内的操作摘要；换控制端仍能看到旧端已接受的工作。结果最多保留 128 条、总计 4 MiB、每条 256 KiB、十分钟，运行中记录不回收，接受前为结果预留空间。当前控制代次的序号窗口阻止已回收请求再次执行；过旧序号、缓存消失或实例变化均按结果未知处理。客户端断线只返回包含原身份和序号的 `outcome_unknown`，不自动重发。

查看读取使用明确清单：终端 show/read/wait 只查 live 终端，不隐式恢复；工作区快照不执行 Git；用量快照不触发后台认证或网络查询；配色只接受当前控制者上报。历史列表、搜索和详情已经核对并开放：可维护目标端的派生索引，不改原会话、不恢复终端；强制索引、会消费消息或修改源记录的接口不按名称推定只读，尚未适配的入口拒绝。带桌面身份的 Client 不可通过通用 Open 绕到独立写入口，远程 Client 缺身份时只允许发现与控制协议。

窗口接入的主机状态层为每个目标保留独立连接代次和固定身份 Client。只有第一次连接本机时自动申请一次；远端连接、重连和切回均从查看开始。心跳失败后降为查看，即使状态查询仍显示原控制者也是自己，也不自动恢复写入。离开主机立即使旧快照、确认回调和排队中的连接失效；迟到的接管结果只释放其取得的那一代租约。接管回复丢失不重发，限时查询状态，只释放仍属于本端且比请求时更新的租约；网络仍不可达时由服务端租期回收。该状态层尚未接到窗口入口。

窗口动作已开始绑定固定请求上下文：终端创建、关闭、清屏和项目/工作区创建、移除、重定位在派发协程或打开确认框前捕获 Client 与控制代次，旧确认不能借用后来取得的身份。轮询与动作结果在主线程实际应用时再次核对来源；换身份后的首轮强制提交，避免已失效的排队结果压掉新状态。远端轮询不按本机路径清理工作区，也不查本机 HEAD 或用远端 PID 统计本机进程；移除远端项目不按本机目录是否存在判断仓库丢失。添加远端项目与重定位工作区使用目标目录选择弹窗，不打开本机选择器：可输入绝对路径、进入子目录或返回上级，只列目标目录（包括目录链接）；添加项目从 `/` 开始，重定位从原路径的父目录开始。成功加载当前目录后才允许选择，权限或不存在错误留在弹窗中，输入修改后须重新加载；读取和最终选择均绑定原主机及控制身份，取消、切换主机或换控制身份使旧回调失效。只有选定后才调用目标项目/工作区写入口。输入中的 `link/..` 由目标文件系统按软链接实际指向解析，添加项目不提前清理父目录段；普通软链接项目仍保留链接显示路径。讨论轮询固定使用本机 Client：查看远端工作区时仍每秒更新本机讨论列表和未读，详情仅在本机讨论页需要时获取；所有讨论与局域网协作请求、附件路径都留在本机，远端工作区轮询不携带讨论数据。终端改名、收回手机尺寸和恢复历史会话也已绑定固定请求：查看状态拒绝修改，尺寸标记等成功回复才改变；改名输入与串行队列不借用后来取得的控制权，带身份的改名失败或结果未知不自动重发，也不套用旧 ui.json 的待交名字。历史恢复的添加项目确认与后续恢复仍使用原主机、路径和身份，迟到结果不切换工作区。其他页面动作仍须接入，当前这些保护通过模拟 Unix RPC 验证。

历史列表、搜索和详情读取已固定请求身份，防抖等待、轮询、排队到主线程的结果及错误都会核对主机和查询序号；同一会话重新打开也不接受较早的详情。详情按需返回目标端的上下文用量，远端字段缺失时不回退读取同路径的本机文件。远端会话目录不作为本机访达链接。历史删除经 `history.trash` 在目标端接受控制身份、核对会话路径、复查运行状态，并与 Posse 恢复入口串行；使用无需窗口的 macOS 废纸篓适配，刷新删除后的索引，部分失败保留真实错误。恢复请求也携带文件路径，重复 ID 不再选错文件。助手 Markdown 图片已接入目标资源服务，根是绝对的会话 Cwd，否则用会话文件父目录；加载器固定主机、会话路径和详情请求代次，换会话、换主机或新详情到来会取消旧读取并丢弃迟到解码，不读本机同路径。工具文本仍按纯文本展示，会话媒体由现有图片面板提供。

聊天目录已由目标端发现和创建：`daemon.status.chat` 返回目标配置的路径和已有工作区 ID，发现不会建目录；`chat.ensure` 在桌面写入门禁内核对预期路径、创建目录并登记项目，已有聊天直接复用，同名项目时选目录名。同一实例的重复请求沿用普通操作结果缓存，不自动重做。远端窗口不读取本机聊天配置，不在本机建目标目录；查看可进入已有聊天，创建、启动与转为项目使用目标控制身份，迟到结果不跳转。远端聊天菜单不提供本机访达打开路径，目录设置仍在目标 Mac 修改。主机入口尚未开放，这些链路通过隔离目录及模拟 RPC 测试。

主机视图上下文各自持有稳定对象，切换只更换当前对象，保留文件编辑器缓冲区、标签、分栏和选中工作区；退出检查所有上下文的未保存文档。切换释放终端显示连接和旧控制租约，不发送关闭终端请求，切回也不恢复旧确认的有效性。窗口主题、字体和快捷键共用，本机 `ui.json` 保持原位置；其他主机的界面状态写在本机 home 下的 `host-ui/<主机ID摘要>/ui.json`，不写目标 Mac 的路径。保存未保存文档时按原对象归属核对连接，可写的本机文档即使隐藏也能保存；已失效或失去控制的文档保留修改，远端文件服务尚未接入时拒绝用本机路径代替。隐藏文档的覆盖确认显示在当前页面，仍绑定原保存请求。设置和更新页面固定本机，语言选择与 Dock 角标由窗口共用；切换清除待补报的已读缓存，切回后可重新上报。导航把工作区目标与当前显示页面分开：讨论、全局技能、手机、设置固定本机，浏览其他主机期间入口与页面标题标明「本机」；工作区、聊天、任务、历史恢复所选主机。进入本机页面不会覆盖原主机的标签和选择，关闭本机页面可返回原主机工作区。远端任务不提供本机「打开讨论」，相同讨论 ID 不跨主机解释。全局新建菜单的项目、工作区和任务动作先显示所选主机，手机入口固定本机；聊天右键菜单仅在选中动作时显示聊天所属主机，收集菜单项不切换页面。当前窗口 `Run` 只注册本机，测试通过内部切换入口和离屏界面验证保留与隔离，尚无可操作的主机切换入口。

这些接口目前用于后续窗口接入与测试，尚未宣布完整的桌面控制能力。窗口主机切换、本机窗口的控制身份、历史与设备入口适配、文件/Git 服务和跨入口写入协调仍须继续接入，不能把当前基础当成完整的查看/接管模式。

## 写入协调基础

目标 daemon 已把项目/工作区的创建、删除、合并、重定位和任务创建 worktree，以及手机切分支接入共享资源协调。路径按实际软链目标解析，目录操作与子路径写入互斥；同一 Git common-dir 的多个 worktree 共用仓库键。多资源一次取得，冲突请求按排队顺序执行，不冲突的资源可并行；等待可取消，释放或取消后不保留空闲锁记录。取得锁后重查项目/工作区登记、实际路径和仓库身份，变化时返回冲突。手机切分支只占用实际仓库路径与 common-dir，对项目登记持共享键，同项目的独立仓库可并行，无关损坏 worktree 不阻断操作；项目登记修改持独占键，与这些共享占用互斥。手机在取得锁后重新读取工作区、分支、未完成的 Git 操作和 agent 状态。项目添加和重定位取得锁后再次确认目标目录存在，原路径软链失效仍可清理登记或重定位。

独立 CLI 和手机工作区写入也登记在交接/退出门禁内，排队中的写入阻止 handoff；交接的新 daemon 取得 home 锁前拒绝这些写入。正常退出取消并收拢已登记的工作，随后才关闭存储。它们仍是独立操作，不需要桌面控制权；桌面已接受的请求继续由已有执行器持有，不重复登记。创建 worktree 的检查、建目录、登记与失败回滚在同一次资源占用内；setup 脚本在释放资源锁后运行，避免脚本反向调用 Posse 等待自身，生命周期仍保留到脚本退出。

## Git 文件版本与 diff
