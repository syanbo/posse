# 界面

窗口各部分的行为。

- 外观的取向和字号、颜色、圆角等规则见 `docs/design.md`。历史里自己的消息是靠右的强调色淡底；侧栏的工作区两行（名称，下面是路径或分支）。状态：工作中是陶土色、像 Claude Code 那样来回变换的星号（减少动态效果时是中性色的实心蜂巢格），待处理是琥珀色带点的蜂巢格加"待处理"文字，启动中是中性色空心蜂巢格，看过的本轮完成（空闲）和还没有状态的一样不画（常驻进程里照旧是空闲，`terminal wait`、任务投递按它；手机端相同），终端标签上的 agent 只剩 agent 图标，等待任务是陶土色波形（见侧栏一条）；本轮完成时你不在看的会话照 Orca 换成陶土色铃铛（见完成未读一条）。发送类输入是一体输入区，⌘↩ 发送。浮层、对话框和弹出面板出现时有 160ms 的淡入，只播一次。改动文件列表（提交详情、分支比较、Push、回滚）都按目录排成树。
- 终端快捷键（`internal/app/termkeys.go`，键登记在快捷键表里，默认照 Ghostty、iTerm、Orca）：Option 不当 Meta。⌘←/⌘→/⌘⌫ 发 Ctrl+A/E/U，⌥←/⌥→/⌥⌫ 发 Meta+B/F/退格；Claude、Codex 终端里 ⇧↩ 发 Ctrl+J（换行不发送）；⌘↑/⌘↓ 回滚到顶/到底；这些在全屏程序（vim、less）里原样交给程序。⌘K 由常驻进程清屏和回滚区（之后接入的快照也是空的）再发 Ctrl+L 重画。⌘A 全选走 Edit 菜单。⌘⇧[ / ⌘⇧]（⌃Tab / ⌃⇧Tab）按侧栏从上到下的顺序切标签：一个工作区里先是 shell 和文件，再是侧栏里列出的 agent 会话（worker 跟在派发方后面）；到头了切到上一个 / 下一个有标签的工作区（跨项目），停在它的最后一个 / 第一个标签，侧栏跟着滚到那一行；只有一个工作区有标签时在它里面绕回来。
- 侧栏：顶上的任务、历史、技能、手机、聊天照 Arc 的置顶磁贴排开，聊天在第二行第一格（图标下面写名字，不带悬停提示；任务有待处理时右上角是琥珀色蜂巢格、进行中写个数，手机连着时右上角是绿点，聊天是它里面最要紧的会话状态）。「聊天」是临时对话的入口，见下面的聊天一条。工作区也能照 Arc 的置顶网址固定到这里：把项目下面的工作区行、单行的项目或多工作区项目的标题行（固定主工作区）拖上来，指针停在哪一格，那一格就空出来（描一圈强调色）、后面的磁贴带动画往后让，松手就固定在那里；工作区右键「固定到顶部」「取消固定」也行，固定的磁贴拖回项目列表就取消。磁贴连同五个全局页面一行四块、最多 12 块（三行）（照 Arc，块离侧栏左右两边、顶上和块之间横竖的间隔都是 8；侧栏最窄时块是正方形，侧栏的最小宽度由此算出，`sidebarMin`；拉宽时块跟着变宽、高度不变），都能拖动换位置：照 Arc，拖着的磁贴原来的格子收拢，指针所在的格子空出来，别的磁贴带动画让开，顺序存在 ui.json 的 `topTiles`（`internal/app/pinned.go`）。固定的工作区：主工作区用项目的图标和名字，别的用工作区自己的，长名字截断；右上角是它终端里最要紧的状态（和会话行同一口径：等待任务的会话是波形，不因本轮完成没看算成铃铛；工作区行、收起的项目行的汇总也一样）；点了切到这个工作区，停在上次看的标签；右键是工作区菜单；工作区不在了就不画，项目树里照常列出它。顶上的磁贴固定不动，下面的项目列表单独滚动。从访达把文件夹拖到项目列表上（描一圈强调色），松手先确认再加成项目，几个一起拖时一次确认，加好后切到第一个的主工作区；已经是项目的不再问、直接切过去，拖来的不是文件夹时报错（`internal/app/projectdrop.go`）。确认框（加项目、关闭、删除这类共用的 `confirmDialog`）点遮罩不关，只有取消按钮和 Esc 关，免得误点丢掉要确认的事。键盘：打开时选中取消（误按回车不会关掉、删掉东西），←→ 和 Tab 在取消和确认之间换，回车、空格按下选中的那个；选中的按钮外面隔一道缝描一圈聚焦色（`confirmButton`）。侧栏右边一列图标（顶栏的侧栏开关、筛选、各行的展开箭头、底栏的齿轮）对在同一条竖线上（`sideIconCenter`）。项目 → 工作区（只有主工作区时省掉这层；项目下面的主工作区是房子图标，和项目行的文件夹区分开，worktree 是分支，同目录工作区是文件夹）→ 运行中的 agent 会话（shell 只在标签栏，会话名照 Orca 比正文小一号，用 `fsSmall`）；会话行首一直是 agent 图标（`smallIcon`），忙起来也认得出是谁，接着是名字，待处理、已完成的文字和收起的 +N 在行尾；状态图形画在行左边的状态槽里（`statusSlot`，占一层缩进，对着上一层行首图标的中线，图标调到最大时贴着槽的右边），点击、拖动和悬停都按包着状态槽的整行算；空闲、还没有状态时槽空着，选中、悬停的底色从第一个可见图形前留出侧栏行的内边距处开始：有状态图形时包着状态槽（连同 worker 的缩进），槽空着时跳过缩进和空槽、从 agent 图标前开始。worker 的缩进放在状态槽前面，状态紧挨着自己的 agent 图标、对着派发方行首图标的中线；「只看运行中的会话」的平铺列表也留状态槽。任务的 worker 排在同一工作区里派发它的会话下面、多缩进一层，照文件树画连接线（`internal/app/workerlines.go`）：竖线走在派发方状态槽的中线下面，从派发方这一行的下边缘开始（派发方没有状态图形时，顶端从它的 agent 图标前横着出来、圆角拐下去，不从空白里冒出来），到每个 worker 拐过去，中间的是 ├、最后一个是圆角的 ╰，横线停在 worker 的状态图形前，没有状态（空闲）时一直连到 agent 图标前，不管 worker 什么状态都连着；嵌套的每层各画一列，上层还有 worker 时竖线穿过下层的行；线一律是分隔线叠在侧栏底上的颜色（不透明，`guide`）。派到同一项目别的工作区（worktree 这类）的 worker 不画影子行，只在它所在的工作区里列出，派发方和它之间直接连线：线走在工作区列表左边、对着项目图标中线的空当里，像一个「[」，最上一头圆角拐下、最下一头圆角拐出，中间的横着接上，横线照样停在状态图形或 agent 图标前；几个派发方各有一条竖线、往左依次错开，一头收在折起的派发方下面时不连（`remoteLinks`）。派到别的项目的 worker 在派发方下面排在同一工作区的 worker 后面，是一行影子（几个时按侧栏里项目、工作区的先后排）：状态图形、图标和文字都淡一些，线照常，第二行写「项目 · 工作区」，照样连线，单击切到它真正所在的工作区和会话、滚到它真正那一行，右键和会话行一样；方向键不经过影子行，它下面的 worker 不再展开，worker 所在的工作区里照常列出它。派发方是用户时照常排，不画线；「只看运行中的会话」不嵌套，也不画；派发方那一行和项目行一样单击展开、已经在看它时再单击收起它下面的 worker（默认展开，不记进 ui.json，没有箭头按钮），收起时写 +N，有 worker 待处理时派发方这一行显示待处理，当前会话收在里面时派发方算选中。派发方有进行中的任务、又阻塞在 `posse task wait` 上或停下来等提醒时，状态是"等待任务"：照 Orca 后台任务的 Activity 波形，陶土色，一段亮的像心电图一样从左边进、右边出（描 1 秒、两头缓动，再停 0.3 秒；减少动态效果时静止）。项目列表上面是一行小标题：左边写「项目」，右边是「只看运行中的会话」的筛选开关（漏斗图标，开着时垫强调色淡底、标题改写「运行中」，存在 ui.json 的 `sidebarGroup`）：打开后把所有项目里的 agent 会话（含空闲和未恢复的）平铺成一列，第二行写「项目 · 工作区」（只有一个工作区的项目只写项目名），worker 不嵌套、不能拖动排序；切进来、重开窗口时按状态排一次（待处理、完成没看、工作中和等待任务、启动中、空闲、未恢复），之后新出现的会话插到同状态那一段末尾，已有的会话状态变了只换状态图形、不挪位置，免得一列跟着状态来回跳；没有会话时写「没有运行中的会话」（连不上常驻进程时不写）。同状态的先后照「项目」看法，worker 紧跟在派发方后面。项目行首的图标可以自定义：右键项目选"更换图标…"，填一个 emoji 或一两个字（用强调色，放不下时按比例缩小），或选一张图片（PNG、JPEG、GIF、WebP、BMP、SVG，一律缩到长边 96 存成 PNG，SVG 先垫黑底、白底各画一遍反推出透明度；原文件之后挪走、删掉都不影响），"恢复默认"换回文件夹。图标和图片都在 `$POSSE_HOME/project-icons`（`icons.json` 键是项目 ID，`internal/projicon`），不放 ui.json：手机首页也显示同样的图标，由常驻进程读（见 `mobile.md`）。换掉的图片一并删掉，项目不在了（窗口、CLI 移除都算）时窗口在下一次轮询删掉它的图标，图片读不了时显示默认图标（`internal/app/projicon.go`）。项目、会话、终端标签和文件标签都能按住拖动排序，落点是一道强调色的线；会话和终端标签共用一个顺序，按工作区存在 ui.json 的 `termOrder`，新开的终端排在后面。顶栏照 Orca：红绿灯（在 40 高的顶栏里上下居中）右边是应用名 Posse，侧栏开关在侧栏顶栏最右边，侧栏顶栏底下的分割线和标签栏的接成一条；设置按钮在侧栏底栏最右边（新建菜单在左边）。开关和 ⌘B 收起展开，侧栏从左边缘滑进滑出（200ms），应用名固定在原位不跟着滑，开关随侧栏滑走；侧栏不占位置时开关跟在应用名后面，主区域顶栏让出它们的位置；拖右边缘调宽（默认宽度和范围见 `docs/design.md`），松手才写 ui.json（`sidebarHidden`、`sidebarWidth`）。
- 聊天：侧栏顶上的「聊天」切到聊天目录（默认 `~/Posse`，开发包和测试的 home 也用它）的工作区，停在上次看的标签；第一次点时建目录、加成名叫「聊天」的项目（已有同名项目时用目录名），之后它和别的项目一样列在项目树里、能删，删了再点就重新加。⇧⌘N（快捷键表的 `newChat`）切过去并用上一次聊天的 agent 再开一个，还没聊过时只切过去、在空工作区的卡片里选 agent。在这个工作区里开的 agent（窗口、手机、`posse terminal create` 都算）由常驻进程各建一个按「月日-时分」命名的子文件夹（同一分钟加 `-2`），在里面启动；名字建好就不改：改名会让运行中的 agent 失去工作目录、Claude 按路径存的会话接不上。普通终端在聊天目录本身；聊天里派出的 worker（`posse task start`）在派发方的子文件夹里，相对路径指同一批文件。终端关掉（或 shell 自己退出）时，按启动时的目录删掉没留下文件的子文件夹（只删这种名字、在某个项目目录正下方的空目录，`internal/daemon/chat.go`）；不删的：常驻进程退出时（重启后恢复的会话回到原来的文件夹）、已经转成项目的、还有别的终端在里面启动的。删掉的在历史页恢复那次会话时建回来。历史页按路径前缀把这些会话都归到聊天项目下。会话右键（侧栏会话行、标签）多出「在访达中打开文件夹」和「转为项目」：把它的子文件夹原地加成一个独立项目，不挪目录。聊天工作区已经有「聊天」磁贴，不能再单独固定到顶上。目录在设置「通用」的「聊天」里改（存 `$POSSE_HOME/agents.json` 的 `chatDir`，只有窗口写，手机和 CLI 改不了），换了以后原来的项目照常留着。信任提示：Claude 认上级目录的信任，信任过 `~/Posse` 后子文件夹不再问；Codex 对不是 git 仓库的目录不问；Grok 只认完全相同的路径，每个新聊天要按一次 y（Posse 不替用户写 `~/.grok/trusted_folders.toml`）。

- 分栏（`internal/app/layout.go`）：一个工作区的主区域可以左右、上下任意分成几格（最多四格），是一棵分割树，同方向连着分的摊平成一层；每格有自己的标签栏，标签是终端或打开的文件，每个标签只在一格里。贴着窗口顶边的那几格的标签栏在标题栏的位置（能拖窗口），右上角那一格的标签栏右边是分支、Git 日志和文件栏这些按钮；右侧面板、Git 日志浮在标签栏下面。标签的先后仍按工作区的终端顺序和打开的文件顺序（侧栏会话的顺序不变），分栏只记每个标签在哪一格。分栏的办法：把标签（或侧栏的会话）拖到某一格内容的上下左右边缘（那一边长度的四分之一，最多 140pt；几条边都够近时取最近的），那半边盖上强调色的淡底，松手在那一边拆出新的一格；拆完两半宽不到 240pt 或高不到 140pt、已经四格、标签是这一格唯一的、或它所在的格就紧挨在那一边且只有它一个标签（放下去还是原样）时不拆。拖到某一格内容的中间（整格淡底）、那格的标签上或标签后面的空处，就移进那一格；同类标签之间照旧排序。「向右分栏」（终端里 ⌘D）、「向下分栏」（⇧⌘D）在焦点格右边、下面拆出一格放一个新 shell，满了或这一格太小时提示；标签右键有「移到右边新分栏」「移到下方新分栏」「合并所有分栏」。「合并所有分栏」（⌃⌘D）把所有标签合回一格，一个都不关；「切换分栏」（⌘]、⌘[）按从左上到右下的顺序换焦点格。这几个键都只在焦点在终端里时认，文件里 ⌘D、⌘] 还是编辑器的。选中的标签就是焦点格选中的那个：关闭标签、会话按钮、查找栏、拖文件、⌘S 都作用于它；在另一格的内容上按下（终端、编辑器、预览）或点了别格的标签，焦点就换过去（只看按在哪，拖标签松手、终端自己拿到键盘焦点都不算）；在侧栏、⌘1…9 选了别格的终端，焦点跟到那格；新开的终端、新打开的文件放进焦点格（点哪格的"+"就先把焦点给那格）；文件树单击的预览标签只换掉焦点格里的那个，移到别的格的文件转成常驻。分栏时焦点格选中的标签底下有一道强调色的短线。关掉一格选中的标签换成同一格挨着的那个；一格的标签都关了这格就收起、空出的地方给同一层旁边的格，焦点到原来排在它前面的格，只剩一格时回到不分栏。每格只接入它选中的那个终端。格之间的分隔线拖动时各格先不变，只画一条跟着指针的线，松手才改比例（每格至少宽 240pt、高 140pt），程序只按新大小重排一次；双击分隔线平分那一层。分栏按工作区存在 ui.json 的 `panes`（分割树、每格的标签、选中的那个、比例和焦点格，以前的 `splits` 读进来时换成左右两格），重开窗口还在；终端不在列表里时它那格不显示、记录留着（常驻进程交接时可能有一次轮询的终端列表不全），回来还在原来那格。手机、任务、恢复终端都不感知分栏。
- 终端里的链接：鼠标放上去有下划线和手形指针，原地单击或 Cmd+点击打开，拖动是选文字，程序开着鼠标跟踪（Claude、Codex）时也一样、这一下不交给程序（改在 `third_party/mygo` 的终端插件里）；指向不存在文件的链接不显示下划线、点不了。终端环境带 `FORCE_HYPERLINK=1`（和 Orca 一样），Claude Code 才会把 `[Image #N]` 输出成超链接。单击弹出链接卡片，Cmd+点击直接打开，Shift+Cmd+点击交给系统（`internal/app/links.go` 的 `openLink`）；设置「通用 › 终端链接」的「单击直接打开」（ui.json 的 `linkClickOpens`）把单击和 Cmd+点击反过来，「⌘ 点击和 ⇧⌘ 点击互换」（`linkSwapSystem`）把直接打开和交给系统的按法对调，卡片里对应操作右边的按法提示跟着换。网址的卡片是网址和后面的复制按钮、在 Posse 中打开、在浏览器中打开；直接打开是在网页标签里打开（不是 http、https 的交给系统），交给系统是默认浏览器。文件链接（如 Claude 的 `[Image #N]` 指向的 `file://`；没做百分号编码时 `#`、`?` 会被截掉，截出来的路径不存在才按原文再认，截出来的文件本身在就用那个）和路径的卡片：顶上是路径和后面的复制按钮，下面是在文件标签中打开（排第一，跳到路径带的 `:行`）、在文件栏中显示（打开文件树、展开上级目录并选中它，只认当前工作区里的路径；当前文件换了或在树上点了别的就不再选中它）、打开、在访达中显示；网页文件（`.html`、`.htm`、`.xhtml`）的卡片在最前面多一项「在 Posse 中打开」，直接打开的按法写在它右边，在网页标签里打开渲染后的页面，「在文件标签中打开」挪到第二项、不写按法（文件标签里默认也是预览，见 `files.md`）；直接打开时网页文件在网页标签里打开，其余文件在终端所在工作区的文件标签里打开（文件属于别的工作区也一样，就在正看着的会话旁边预览、不切走；代价是文件树定位不到它，⌘P、跳到定义按这个工作区算；卡片里的「在文件标签中打开」同样）并跳到行，目录在文件栏中显示（不在当前工作区里的弹卡片；文件和终端都不在任何工作区里时也弹卡片）；交给系统时文件用默认程序打开，目录在访达中打开。终端自动换行的、程序在路径的 `/` 后自己换行的链接按整条识别，悬停、点击哪一行都是完整的链接。
- 终端里查找（`termfind.go`）：⌘F 打开右上角的查找栏（快捷键表「终端 → 在终端里查找」；有单行选区时拿它当搜索词，关了再开接着搜上次的词；⌘F 后紧跟着打的字在输入框拿到焦点之前就到了终端，由终端插件的 `OnText` 交回来接进搜索词，不发给程序），搜索交给终端插件里 libghostty 的 find：窗口这份内核的屏幕和回滚区（4 MB，和常驻进程一样），只认原文、ASCII 字母不分大小写，不支持正则和整词；程序还在输出时命中跟着变，回滚区大时分帧搜、计数边搜边涨。命中铺蜂蜜色淡底，当前那个深一点（和 Markdown 预览的查找一样），右边是第几个 / 共几个，1 是最新的。回车、⌘G 往上（更早的输出），⇧回车、⇧⌘G 往下（按键跟着编辑器的查找下一个、上一个；栏开着时 ⇧⌘G 不去开关改动页），Esc 关掉并清掉高亮，焦点回到终端；全屏程序里查的是它那一屏。状态跟着终端视图走，切到别的终端或别的页面就关掉；被常驻进程断开、重新接入时照旧开着、按原来的词再搜；终端改了尺寸丢了选中时选回最新的。agent 终端的查找栏多一个历史按钮，搜不到时下面一行"在历史里搜"：Claude 重画时连回滚区一起清掉、Codex 在备用屏幕上，终端里只搜得到眼前这一屏，点了带着这个词、按这个 agent 筛选跳到历史页。
- 网页标签（`internal/app/web.go`）：http、https 网址和本地网页文件在当前终端所在工作区的文件标签里打开，用系统的 WebKit（mygo 的 `WebView`），和 diff、比较一样不对应磁盘文件、不记进 ui.json，每次新开一个标签，打开后键盘交给页面。标签上是地球图标和页面标题（还没有标题、或新页面没有 `<title>` 时是主机名），悬停提示网址。上面一行是后退、前进、重新载入（载入中换成停止）、地址栏（没写协议的补 `https://`；localhost、IP 地址和 `.local` 补 `http://`，开发服务器一般没有证书；`file://` 网址和绝对路径是本地文件，经 `loadFileURL` 载入，页面能读文件所在目录和子目录，标签上没有标题时写文件名；不像网址的不跳；Esc 恢复当前地址并把键盘交回页面）、复制链接、在浏览器中打开。载入失败（比如开发服务器还没起来）时页面位置写「打不开 <网址>」和原因，地址栏留着原网址，重新载入按原网址再试；被新跳转打断的不算失败。页面里 `target=_blank` 和 `window.open` 的链接在旁边再开一个网页标签（工作区已经不在了就交给浏览器）。跳转、载入、标题由页面事件更新；单页应用用 pushState、hash 换地址不发事件，网页标签看得见时每秒再对一次地址和前进后退。页面跑在系统的 WebContent 进程里（不算进窗口的内存），切到别的标签时留着，关掉标签、工作区换了目录或被删时销毁；窗口进程在第一次打开网页后多出 WebKit 框架约 20 MB，关掉也不回落。窗口被别的窗口完全挡住时 mygo 不画、WebKit 也不渲染，露出来再补上。⌘R 重新载入、⇧⌘R 不用缓存重新载入（菜单栏 View 里，网页有焦点时也认：键盘在 WebKit 手里时窗口的快捷键收不到，菜单先拿到按键；当前不是网页标签时不起作用）。手机预览（`internal/app/webdevice.go`）：工具栏的手机按钮选机型（iPhone 15/16 393×852、iPhone SE 375×667、Pixel 8 412×915、iPad mini 768×1024）和横屏，⇧⌘M 用上次选的机型开关（记在 ui.json 的 `webDevice`）；按标签记，不存盘。Mac 上的 WebKit 不认 `<meta viewport>`、排版宽度就是视图宽度，所以把网页放进机型大小的视图、居中放在底色上，换上对应手机浏览器的 UA 并重新载入一次；窗口放不下时连视图带页面按同一比例缩小（页面缩放保持 CSS 宽度是机型的宽度），上面一行写机型、尺寸和缩放。触摸事件、安全区、设备像素比模拟不了。agent 能用 `posse web` 打开、读取和操作网页标签，见 `docs/features/agents.md`。
- 完成未读（`internal/daemon/unread.go`、`internal/app/unread.go`）：agent 从工作中变成空闲、又没有手机开着这个会话时，常驻进程记成未读，和手机共用（交接时带过去，常驻进程重启就没了）；窗口有焦点、正看着这个会话时报 `terminal.seen` 清掉，报之前它自己不画铃铛，手机开着它的终端页或会话页也算看过。标签、侧栏会话行和收起的项目、工作区汇总都画铃铛（汇总里次于待处理、高于工作中），未读期间铃铛隔一会儿摇一轮（摇 800 ms、来回摆三下越摆越小，再停 1.6 s；系统设了减少动态效果时不摇），侧栏会话行在铃铛前写"已完成"；它再开始工作也清掉。
- 系统通知和 Dock 角标（`internal/app/app.go` 的 `noticeStatus`、`noticeTitle`、`badgeCount`，任务的在 `tasks.go`）：由窗口进程发，关掉窗口后就不再有（窗口进程跟着退出）。窗口每次轮询比较每个 agent 终端的状态：进入待处理时发「<Agent> 等待你处理」；从工作中变成空闲且常驻进程记成未读时发「<Agent> 已完成」（手机看着时完成的不算未读，不发）；窗口有焦点、正看着这个会话时不发；窗口刚打开的第一轮只记下状态。正文是工作区名，后面接 agent 的最后一条消息。通知 ID 是 `posse:<工作区>:<终端>`，同一会话的新通知替换旧的，按工作区分组，点通知切到那个会话并把窗口提到前面。任务的问题、完成、失败、worker 意外退出另发（`posse-task:<任务>`，点开是任务页）。Dock 角标是侧栏显示成待处理和铃铛的 agent 会话数（按 `sessionStatus` 算：等待任务、还没恢复的不算，正看着的会话完成了不算），轮询的数据变了、看着的会话换了（含窗口失去焦点）时重算，数变了才更新。设置页「通用 › 通知」可以分别关掉通知和角标，关掉角标时马上清掉。
- 窗口最小 900×560：默认宽的侧栏旁边，默认字号的终端还有约 72 列。窗口窄时主区域状态栏先裁掉左边的套餐用量，右边的按钮不被挤掉。
- agent 痕迹的清理（`internal/app/traces.go`，记账见 `agents.md`）：删工作区时先查它的痕迹，有就把确认框换成带勾选的列表（没有时照旧），确认后先删工作区，成功了再清勾选的（worktree 工作区先查未提交的改动，有就不删、报在错误条上，没有再关掉它的终端后删除，所以开着终端也删得掉）；项目行右键「清理 agent 痕迹…」列出整个项目的。每项是路径、大小（后台算，目录最多数 5 秒）、在访达中显示，下面一行是 agent、时间和类型。新建的默认勾上，移到废纸篓（项目里清理时留下它的终端还开着的不勾）；自建的 worktree 默认不勾，勾了用 `git worktree remove`（有未提交改动时 git 拒绝，报在错误条上）；改过的已有文件和配置只列出、不给删。清掉的从账本里去掉；常驻进程是旧版本、没有这个接口时当作没有痕迹。
