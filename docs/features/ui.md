# 界面

窗口各部分的行为。

- 外观参照 Claude 桌面端的克制，配色、字号、字重和控件的约定见 `internal/app/style.go` 开头（依据见 `docs/plans/ui-claude-polish.html`）：暖灰底色，强调色是 Claude 橙（深色 #D97757、浅色 #C15F3C），默认 8px 圆角，终端底色和卡片一致；选中项是强调色淡底，所有列表都不画竖条，侧栏选中的文字也不加粗；历史里自己的消息是靠右的强调色淡底；侧栏的工作区两行（名称，下面是路径或分支）。状态：工作中是陶土色、像 Claude Code 那样来回变换的星号（减少动态效果时是中性色的实心蜂巢格），待处理是琥珀色带点的蜂巢格加"待处理"文字，完成（空闲）是绿色空心蜂巢格，启动中是中性色空心蜂巢格，等待任务是陶土色波形（见侧栏一条）；本轮完成时你不在看的会话照 Orca 换成陶土色铃铛（见完成未读一条）。发送类输入是一体输入区，⌘↩ 发送；可滚动列表在还有内容的一边渐隐。浮层、对话框和弹出面板出现时有 160ms 的淡入，只播一次。改动文件列表（提交详情、分支比较、Push、回滚）都按目录排成树。
- 终端快捷键（`internal/app/termkeys.go`，照 Ghostty、iTerm、Orca 的默认）：Option 不当 Meta。⌘←/⌘→/⌘⌫ 发 Ctrl+A/E/U，⌥←/⌥→/⌥⌫ 发 Meta+B/F/退格；Claude、Codex 终端里 ⇧↩ 发 Ctrl+J（换行不发送）；⌘↑/⌘↓ 回滚到顶/到底；这些在全屏程序（vim、less）里原样交给程序。⌘K 由常驻进程清屏和回滚区（之后接入的快照也是空的）再发 Ctrl+L 重画。⌘A 全选走 Edit 菜单。⌘⇧[ / ⌘⇧]（⌃Tab / ⌃⇧Tab）按标签栏顺序切标签。
- 侧栏：项目 → 工作区（只有主工作区时省掉这层）→ 运行中的 agent 会话（shell 只在标签栏）。任务的 worker 排在同一工作区里派发它的会话下面、多缩进一层（不画连接线；派发方在别的工作区或是用户时照常排）；派发方那一行和项目行一样单击展开、已经在看它时再单击收起它下面的 worker（默认展开，不记进 ui.json，没有箭头按钮），收起时写 +N，有 worker 待处理时派发方这一行显示待处理，当前会话收在里面时派发方算选中。派发方有进行中的任务、又阻塞在 `posse task wait` 上或停下来等提醒时，状态是"等待任务"：照 Orca 后台任务的 Activity 波形，陶土色，一段亮的像心电图一样从左边进、右边出（描 1 秒、两头缓动，再停 0.3 秒；减少动态效果时静止）。项目、会话、终端标签和文件标签都能按住拖动排序，落点是一道强调色的线；会话和终端标签共用一个顺序，按工作区存在 ui.json 的 `termOrder`，新开的终端排在后面。顶栏照 Orca：红绿灯（在 40 高的顶栏里上下居中）右边是应用名 Posse，侧栏开关在侧栏顶栏最右边，侧栏顶栏底下的分割线和标签栏的接成一条；设置按钮在侧栏底栏最右边（新建菜单在左边）。开关和 ⌘B 收起展开，侧栏从左边缘滑进滑出（200ms），应用名固定在原位不跟着滑，开关随侧栏滑走；侧栏不占位置时开关跟在应用名后面，主区域顶栏让出它们的位置；拖右边缘调宽（200–420），松手才写 ui.json（`sidebarHidden`、`sidebarWidth`）。
- 任务、历史、手机、设置这几页顶栏最右边有关闭按钮，⌘W 也关：回到上次看的工作区，放掉页面读进来的内容（历史的列表和打开的会话、任务详情、手机列表），再打开时重读。
- 侧栏是纯色，不用毛玻璃。所有输入框都是一种样子：填充底、不画框、聚焦时一圈焦点色，和标签改名一致。
- 设置页（`internal/app/settings.go`）：⌘,（应用菜单的"设置…"）和侧栏底栏右边的齿轮打开，不在侧栏里。左边是分类，右边只放选中的一类（选的分类不记，每次从「通用」开始）：通用（防休眠）、Agent（权限见 `agents.md`、套餐用量见 `usage.md`）、外观（图标大小，终端和编辑器两张卡片）、关于。终端（字体和字号，存在 ui.json 的 `termFont`、`fontSize`；终端里 ⌘=、⌘-、⌘0 也调它（终端自己的临时缩放经 `OnZoom` 关掉，设置页的数字和终端实际的字号始终一致），按住 ⌘ 滑触控板或滚轮照常滚动、不缩放，见 mygo 的 `NoWheelZoom`）、编辑器（文件标签里的编辑器、diff、逐行追溯，Git 日志里的 diff 和改动卡片的字体和字号，`editorFont`、`editorFontSize`；文件标签在前台时 ⌘= ⌘- ⌘0 调它；旧版没有这一项时取终端字号小一号）。字体在可搜索的列表里选（`fonts.go`），照 Orca 列出系统的全部字体，等宽的排在前面一组、其余在「其他字体」下；第一次打开时在后台列出，运行中新装的字体重开窗口才有；列表只画看得见的行，每项用自己的字体写名字；中文字体照系统语言显示中文名（「苹方-简」，CoreText 的本地化名字，`fontname_darwin.go`），存的仍是原名，中文名和原名都能搜。选的字体后面接上默认字体栈当回退（Nerd Font 的图标、苹方的中文），空是默认的 JetBrains Mono。终端和编辑器各有一块预览，改了马上跟着变：终端的照终端配色画提示符（带 Nerd Font 的分支图标）、ls 和中英混排，编辑器的是一个只读的真编辑器；关于里比较窗口和常驻进程的 `daemon.Build`（git 提交加进程启动时可执行文件的修改时间，有未提交改动时提交后面带 `+`）。对不上时"更新常驻进程"是主按钮：`daemon.handoff` 把终端交给用窗口的包启动的新进程，终端不断，不用确认；窗口的包比常驻进程新（按构建标识里的时间比，打开旧 Posse.app 不会把常驻进程换回旧包）时轮询里自动做一次（`internal/app/upgrade.go`，按常驻进程 pid 只自动试一次，失败报在错误条上，终端不受影响）。"重启常驻进程"会关闭所有终端，先确认，之后窗口用自己的包拉起新的。手机配对在「手机」页。
- 窗口所在的 Posse.app 被换掉（重新打包、覆盖安装）后，侧栏底部出现"Posse 已更新，重开窗口后生效"的提示和"重开窗口"按钮（`internal/app/relaunch.go`）：不重开的话，桌面、文稿里的项目读不了文件、跑不了 git。重开前先处理未保存的文件，终端不受影响。
- 主区域状态栏右边的终端和内存按钮打开浮窗：posse 自己（常驻进程、窗口）和各工作区终端里的程序。终端按整棵进程树统计 phys_footprint，浮窗开着时每 3 秒按工作区算一次；底栏显示的是总内存（posse 自己加终端），终端合计每 5 秒算一次。点终端展开进程明细：shell、agent 本体，和 agent 拉起的每棵子进程（MCP 服务等），名字取自命令行，跳过 npm、node、python 这类启动器。
- 新开的终端在程序画出第一屏之前居中显示蜂巢加载动画和"正在启动 Claude"（shell 终端写"终端"；动画和手机端同一设计：七格蜂巢，外圈顺时针逐格亮起、拖一段渐暗，1.2 秒一圈，减少动态效果时停在一帧）：先跑用户的 shell 配置再启动 agent，Claude 要一两秒才画第一屏，不提示像是没反应。接入 300ms 后才显示（切到已有内容的终端时快照还没到，不闪一下），屏幕上出现过内容或 20 秒后不再检查。
- 和会话有关的按钮在 agent 终端内容区右上角竖排一列：worker 终端的"返回任务"、图片、"技能与工具"；历史按项目，在文件栏的"历史"页。这一列盖在终端内容上，鼠标不在上面、也没开着它的面板时半透明；底部的箭头把它收成贴着右边缘的小把手，点把手展开（ui.json 的 `sessionButtonsHidden`，所有会话共用）。
- "图片"面板（`images.go`，四家会话都有）分两组：agent 生成的在上——Claude、Grok 是工具结果里内嵌的图片（截图 MCP、读进来的图片；`history.ImageScanner` 按 agent 增量扫会话文件，只记位置，用到时按偏移读回那一行。Claude 只认 `type: user` 的行，`api-request-blob` 是副本；Grok 认 `tool_result` 的 `images`，和紧跟在工具结果后面、`synthetic_reason` 不为空的用户消息里的图片），Codex 是 `~/.codex/generated_images/<会话 ID>/`（`ig_` 图像生成、`exec-` 代码产出），Cursor 的会话文件不记工具输出，没有；Claude、Codex、Grok 工具输出里提到的视频文件（androidmirror 录屏返回的路径、命令打印的产物等，`history.VideoScanner` 只认工具输出里的绝对路径，磁盘上还在的才列）也算 agent 生成的，和图片按时间排在一起（Grok 的会话文件没有时间，排在后面），缩略图由 `qlmanage` 取第一帧（缓存在 `$TMPDIR/posse-video-thumbs/`，key 带文件修改时间，录到一半取不到的写完后再取），盖一个播放标记，点开用默认应用播放；粘贴的（`[Image #N]`）在下：Claude 取会话图片目录，Codex 取会话文件里用户消息的 `input_image`（序号取前面的 `<image name=[Image #N] path=…>`；那个临时文件之后可能没了，不读它），Grok、Cursor 取用户消息里 `<image_files>` 列出的文件（各自的 assets 目录，序号是清单里的编号，时间取文件修改时间）。只留缩略图，agent 生成的最多列最近 40 项。悬停在面板左边浮出大图，宽不超过 544、高不超过内容区，竖的长截图整张看得见；点图片在文件标签里预览（可缩放，用预览标签，同时收起面板），视频和不在任何工作区的用默认应用打开；右键有"在访达中显示"和"用系统预览打开"（指定 Preview.app，视频是"用默认应用打开"）。内嵌的图要打开、显示时先从会话文件写到 `$TMPDIR/posse-images/`（是 agent 当时看到的样子）。
- "技能与工具"面板由窗口进程增量只读解析当前终端的会话文件（`history.UsageScanner`），路径优先用 hooks 报的 `transcriptPath`，否则按会话 ID 在各家目录里找；只认实际使用的记录（注入的技能说明、读 SKILL.md 的调用、MCP 调用），系统提示里的技能列表不算。agent 执行的 shell 命令（Claude 的 Bash、Codex 的 exec_command 和 CommandExecution（同一个 id 只算一次）、Grok 的 run_terminal_command、Cursor 的 Shell）由 `history.cliPrograms` 做轻量解析认出运行的程序（引号、分隔符、`$( )`、`<( )`、heredoc、环境变量赋值、sudo/env/timeout 这类包装、`bash -c`、命令里定义的函数），shell 内建和 ls、cat、grep 这类基础工具（`cliSkip`）、相对路径和 Homebrew、系统目录以外的绝对路径不算；来源按本机安装位置判断（`cliSource`：/opt/homebrew，或 /usr/local/bin 下链接到 Cellar 的是 Homebrew，/usr/bin 等是系统自带，其余是其他命令行），一条命令里每个程序记一次。面板顶上是筛选（全部 / 技能和 MCP，记在 ui.json 的 `usageSkillsOnly`，只看技能和 MCP 时不列命令行程序的分组、时间线里也跳过它们），然后是每个技能、MCP 服务的次数，命令行程序按 Homebrew、其他命令行、系统自带分组，下面是时间线（`Usage.Events`，取每行的 timestamp，grok、cursor 的会话文件没有时间），连着调同一个工具合成一项。标签和时间线里的名字点一下复制到剪贴板（底部提示已复制）。
- agent 图标：Claude 取自 simple-icons，Grok、Cursor 取自 LobeHub Icons，都是单色填充路径，放在各家颜色的方块里；Codex 已并入 ChatGPT 应用，用 LobeHub 的 OpenAI 标志，照 ChatGPT 应用图标是白底黑标，加一圈细内描边免得在浅色卡片上融掉。
- 鼠标指针照 Orca（网页习惯）：能点的元素（按钮、链接、列表的可选行等）都是手形，禁用的是箭头，拖动排序、拖文件时是抓握的手；文字输入、终端、编辑器是 I 形，拖边调宽是左右或上下箭头。
- 终端标签可以改名：双击标签或右键「重命名…」原地编辑，回车或点别处保存、Esc 取消，清空或右键「恢复默认名称」回到会话标题或终端标题。名字由常驻进程记着（`terminal.rename`，存在 `terminals.title`，交接后从数据库读回），手机的标签也用它，优先于会话标题；标签、侧栏会话行和内存浮窗都用它代替会话标题和任务标题。界面先把名字记在 ui.json 的 `termNames`，马上换上，常驻进程报上来的一样了才删。
- 菜单（加号、右键、防休眠档位、分支、日志筛选等）都是同一种浮层：悬停是中性透明底，可勾选的项是陶土色对勾，快捷键右对齐（只是提示，不绑定），子菜单在右边展开；↑↓ 移动、→ 展开子菜单、← 收起、回车选中，Esc 或点外面关掉。右键菜单贴着指针，放不下时翻到另一边。文字输入框、可选文字和编辑器的编辑菜单（剪切、复制、粘贴、全选，编辑器还有注释、选择、转换、折叠）样子相同、菜单项是中文。
- 鼠标照 Orca：终端标签和文件标签中键关闭、右键菜单（关闭、关闭其他、关闭右侧；文件标签另有关闭所有文件、复制路径、在访达中显示），终端标签悬停提示完整的名字和标题。标签放不下时用触控板或滚轮左右滚，切到哪个就滚到哪个；照浏览器的标签栏不显示滚动条。标签文字选中时加粗，切换时后面的标签不会左右挪；标题超过标签最大宽度（280）时截断加省略号，关闭按钮始终留在标签里。设置页「界面」的图标大小（小 14、标准 16、大 18，ui.json 的 `iconSize`）统一管图标按钮（顶栏、底栏、会话按钮，框比图标大 12）、侧栏图标，标签页和侧栏行尾的状态小一号。终端的右键菜单由 Posse 提供（`termmenu.go`，`terminal.Options.ContextMenu`）：复制、粘贴、全选、清屏（和 ⌘K 一样由常驻进程清）、复制会话 ID、关闭终端。从访达或文件栏（文件树、改动列表）拖文件到终端贴入路径：图片按粘贴发（agent 认得出粘贴的图片路径，当成附件：都认 png、jpg、gif、webp，另认的按 agent 不同，见 `imageExts`），有特殊字符时用反斜杠转义（路径带单引号时 Claude、Grok 认不出单引号括起来的写法），Cursor 连这个也认不出，改发 `file://` 链接；其余文件单引号转义后当键入、后面带空格；文件栏滑进来的途中不能拖。
- 终端里的链接：鼠标放上去有下划线和手形指针，原地单击或 Cmd+点击打开，拖动是选文字，程序开着鼠标跟踪（Claude、Codex）时也一样、这一下不交给程序（改在 `third_party/mygo` 的终端插件里）；指向不存在文件的链接不显示下划线、点不了。终端环境带 `FORCE_HYPERLINK=1`（和 Orca 一样），Claude Code 才会把 `[Image #N]` 输出成超链接。网址交给默认浏览器；文件链接（如 Claude 的 `[Image #N]` 指向的 `file://`；没做百分号编码时 `#`、`?` 会被截掉，截出来的路径不存在才按原文再认，截出来的文件本身在就用那个）和路径弹出链接卡片（`internal/app/links.go`）：在文件标签中打开（排第一）、在文件栏中显示（打开文件树、展开上级目录并选中它，只认当前工作区里的路径；当前文件换了或在树上点了别的就不再选中它）、打开、在访达中显示、复制路径。
- 完成未读（`internal/app/unread.go`）：agent 从工作中变成空闲时，窗口没有焦点或你没在看这个会话，就记成未读（只在窗口内存里，重开窗口就没了），标签、侧栏会话行和收起的项目、工作区汇总都画铃铛（汇总里次于待处理、高于工作中），未读期间铃铛隔一会儿摇一轮（摇 800 ms、来回摆三下越摆越小，再停 1.6 s；系统设了减少动态效果时不摇），侧栏会话行在铃铛前写"已完成"；窗口有焦点时切到这个会话就清掉，它再开始工作也清掉。
- 窗口最小 900×560：默认宽的侧栏旁边，默认字号的终端还有约 75 列。窗口窄时主区域状态栏先裁掉左边的套餐用量，右边的按钮不被挤掉。
