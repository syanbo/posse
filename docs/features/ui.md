# 界面

窗口各部分的行为。

- 外观的取向和字号、颜色、圆角等规则见 `docs/design.md`。历史里自己的消息是靠右的强调色淡底；侧栏的工作区两行（名称，下面是路径或分支）。状态：工作中是陶土色、像 Claude Code 那样来回变换的星号（减少动态效果时是中性色的实心蜂巢格），待处理是琥珀色带点的蜂巢格加"待处理"文字，完成（空闲）是绿色空心蜂巢格，启动中是中性色空心蜂巢格，等待任务是陶土色波形（见侧栏一条）；本轮完成时你不在看的会话照 Orca 换成陶土色铃铛（见完成未读一条）。发送类输入是一体输入区，⌘↩ 发送。浮层、对话框和弹出面板出现时有 160ms 的淡入，只播一次。改动文件列表（提交详情、分支比较、Push、回滚）都按目录排成树。
- 终端快捷键（`internal/app/termkeys.go`，照 Ghostty、iTerm、Orca 的默认）：Option 不当 Meta。⌘←/⌘→/⌘⌫ 发 Ctrl+A/E/U，⌥←/⌥→/⌥⌫ 发 Meta+B/F/退格；Claude、Codex 终端里 ⇧↩ 发 Ctrl+J（换行不发送）；⌘↑/⌘↓ 回滚到顶/到底；这些在全屏程序（vim、less）里原样交给程序。⌘K 由常驻进程清屏和回滚区（之后接入的快照也是空的）再发 Ctrl+L 重画。⌘A 全选走 Edit 菜单。⌘⇧[ / ⌘⇧]（⌃Tab / ⌃⇧Tab）按标签栏顺序切标签。
- 侧栏：顶上的任务、历史、手机固定不动，下面的项目列表单独滚动。项目 → 工作区（只有主工作区时省掉这层）→ 运行中的 agent 会话（shell 只在标签栏，会话名照 Orca 比正文小一号，用 `fsSmall`）；会话行和终端标签一样，最左是状态图形，接着 agent 图标和名字，图标用 `smallIcon`，待处理、已完成的文字和收起的 +N 在行尾。任务的 worker 排在同一工作区里派发它的会话下面、多缩进一层（不画连接线；派发方在别的工作区或是用户时照常排）；派发方那一行和项目行一样单击展开、已经在看它时再单击收起它下面的 worker（默认展开，不记进 ui.json，没有箭头按钮），收起时写 +N，有 worker 待处理时派发方这一行显示待处理，当前会话收在里面时派发方算选中。派发方有进行中的任务、又阻塞在 `posse task wait` 上或停下来等提醒时，状态是"等待任务"：照 Orca 后台任务的 Activity 波形，陶土色，一段亮的像心电图一样从左边进、右边出（描 1 秒、两头缓动，再停 0.3 秒；减少动态效果时静止）。项目行首的图标可以自定义：右键项目选"更换图标…"，填一个 emoji 或一两个字（用强调色，放不下时按比例缩小），或选一张图片（PNG、JPEG、GIF、WebP、BMP、SVG，一律缩到长边 96 存成 PNG，SVG 先垫黑底、白底各画一遍反推出透明度；原文件之后挪走、删掉都不影响），"恢复默认"换回文件夹。图标和图片都在 `$POSSE_HOME/project-icons`（`icons.json` 键是项目 ID，`internal/projicon`），不放 ui.json：手机首页也显示同样的图标，由常驻进程读（见 `mobile.md`）。换掉的图片一并删掉，项目不在了（窗口、CLI 移除都算）时窗口在下一次轮询删掉它的图标，图片读不了时显示默认图标（`internal/app/projicon.go`）。项目、会话、终端标签和文件标签都能按住拖动排序，落点是一道强调色的线；会话和终端标签共用一个顺序，按工作区存在 ui.json 的 `termOrder`，新开的终端排在后面。顶栏照 Orca：红绿灯（在 40 高的顶栏里上下居中）右边是应用名 Posse，侧栏开关在侧栏顶栏最右边，侧栏顶栏底下的分割线和标签栏的接成一条；设置按钮在侧栏底栏最右边（新建菜单在左边）。开关和 ⌘B 收起展开，侧栏从左边缘滑进滑出（200ms），应用名固定在原位不跟着滑，开关随侧栏滑走；侧栏不占位置时开关跟在应用名后面，主区域顶栏让出它们的位置；拖右边缘调宽（默认宽度和范围见 `docs/design.md`），松手才写 ui.json（`sidebarHidden`、`sidebarWidth`）。
- 任务、历史、手机、设置这几页顶栏最右边有关闭按钮，⌘W 也关：回到上次看的工作区，放掉页面读进来的内容（历史的列表和打开的会话、任务详情、手机列表），再打开时重读。
- 侧栏是纯色，不用毛玻璃。所有输入框都是一种样子：填充底、不画框、聚焦时一圈焦点色，和标签改名一致。
- 设置页（`internal/app/settings.go`）：⌘,（应用菜单的"设置…"）和侧栏底栏右边的齿轮打开，不在侧栏里。左边是分类，右边只放选中的一类（选的分类不记，每次从「通用」开始）：通用（防休眠、恢复终端、终端选区：「选中即复制」开关，默认关，`termCopyOnSelect`，打开后鼠标选中文字松手、全选时就复制到剪贴板，经 mygo 终端插件的 `CopyOnSelect`，改了马上对当前终端生效；通知：「系统通知」「Dock 角标」两个开关，默认开，`notifyOff`、`badgeOff`，见完成未读后面的通知一条）、Agent（各家开关和权限见 `agents.md`、套餐用量见 `usage.md`）、外观（界面卡：字号、字重、粗体字重、图标大小、侧栏项目显示分支和路径（关掉后项目行只留名字，`projectMetaHidden`）、侧栏工作区显示分支（关掉后项目下面的工作区行只留名字，`workspaceMetaHidden`）、字体平滑，默认值、ui.json 字段和各档的推算见 `docs/design.md`；终端和编辑器两张卡片）、关于。终端（字体和字号，存在 ui.json 的 `termFont`、`fontSize`；终端里 ⌘=、⌘-、⌘0 也调它（终端自己的临时缩放经 `OnZoom` 关掉，设置页的数字和终端实际的字号始终一致），按住 ⌘ 滑触控板或滚轮照常滚动、不缩放，见 mygo 的 `NoWheelZoom`；还有字重（默认 400）、粗体字重（默认比正文重 200、至少 600）、行高（字体自身行高的倍数，默认 1）、字体平滑（默认关，`termWeight`、`termBoldWeight`、`termLineHeight`、`termSmooth`）。Core Text 的字体平滑让深色底上的浅色字看上去重一档（13 号 400 平滑后比不平滑的 600 还粗），所以终端默认像 Ghostty 一样不平滑，经 mygo 终端插件的 `Font.Antialiased`）、编辑器（文件标签里的编辑器、diff、逐行追溯，Git 日志里的 diff 和改动卡片的字体和字号，`editorFont`、`editorFontSize`；文件标签在前台时 ⌘= ⌘- ⌘0 调它；旧版没有这一项时取终端字号小一号；字重、粗体字重、行高、字体平滑四项和终端一样（行高是字号的倍数，默认 1.5；粗体用在 Markdown 的标题和加粗上，mygo 编辑器原本不画粗体），`editorWeight`、`editorBoldWeight`、`editorLineHeight`、`editorSmooth`）。字体在可搜索的列表里选（`fonts.go`），照 Orca 列出系统的全部字体，等宽的排在前面一组、其余在「其他字体」下；第一次打开时在后台列出，运行中新装的字体重开窗口才有；列表只画看得见的行，每项用自己的字体写名字；中文字体照系统语言显示中文名（「苹方-简」，CoreText 的本地化名字，`fontname_darwin.go`），存的仍是原名，中文名和原名都能搜。选的字体后面接上默认字体栈当回退（Nerd Font 的图标、苹方的中文），空是默认的 JetBrains Mono。终端和编辑器各有一块预览，改了马上跟着变：终端的照终端配色、用终端同样的字体和平滑设置自己排字画出提示符（带 Nerd Font 的分支图标）、ls 和中英混排，编辑器的是一个只读的真编辑器；关于里比较窗口和常驻进程的 `daemon.Build`（git 提交加进程启动时可执行文件的修改时间，有未提交改动时提交后面带 `+`）。对不上时"更新常驻进程"是主按钮：`daemon.handoff` 把终端交给用窗口的包启动的新进程，终端不断，不用确认；窗口的包比常驻进程新（按构建标识里的时间比，打开旧 Posse.app 不会把常驻进程换回旧包）时轮询里自动做一次（`internal/app/upgrade.go`，按常驻进程 pid 只自动试一次，失败报在错误条上，终端不受影响）。"重启常驻进程"会关闭所有终端，先确认，之后窗口用自己的包拉起新的；关掉的终端重启后标为「未恢复」，见 `agents.md` 的恢复终端。手机配对在「手机」页。
- 快捷键（设置页「快捷键」分类，`keymap.go` 是表、`keysettings.go` 是页面）：Posse 自己的、终端的和编辑器的快捷键都列在这里，按窗口与标签、文件、Git、历史、终端、编辑器（移动、选择、编辑、折叠、查找与跳转）、其他分组，顶上可以按名称或按键（如 ⌘K）搜索。点一组键进入录制，按新组合换掉它，Esc 取消，⌫ 删掉这一组；行尾悬停出现的 + 再加一组；改过的行有"恢复默认"，顶上有"全部恢复默认"。不带 ⌘ ⌃ ⌥ 的打字键和没有修饰键的键（F1–F12 除外）不收；菜单栏系统占用的键（⌘Q、⌘H 这类）录不进来。同一处（窗口、文件标签、历史页、终端、编辑器）的两项不能用同一组键，录了别人在用的会从那一项上去掉并提示；不同处可以重复（⌘K 在终端里清屏、在文件里提交）。录制时窗口快捷键和终端按键一律不认，离开这一页就停止录制。⌘1…9、多行输入框的 ⌘↩ 和系统菜单的几项只列出来、不能改。改过的存在 ui.json 的 `keys`（只存和默认不同的，`Super+Shift+k` 这种写法，和弦用空格隔开）；编辑器的改动经 mygo 编辑器的 `Bindings` 生效（旧键用 `NoCommand` 让出），Markdown 预览和 Annotate 的查找栏跟着编辑器的查找、查找下一个、查找上一个；关闭标签、关闭窗口、打开设置改了重新装菜单。界面上写着快捷键的提示（按钮悬停、菜单右边、空页面的提示）都按表显示当前的键。
- 窗口所在的 Posse.app 被换掉（重新打包、覆盖安装）后，侧栏底部出现"Posse 已更新"的提示卡和"重开窗口"按钮（`internal/app/relaunch.go`）：不重开的话，桌面、文稿里的项目读不了文件、跑不了 git。重开前先处理未保存的文件，终端不受影响：常驻进程从包的副本运行，换包不影响它拉起的终端（见 `docs/plans/terminal-host.md` 的"从副本运行"）。卡片上的 ✕ 只在这次窗口里收起它，侧栏底栏齿轮左边留一个强调色圆点，点了把提示卡放回来。侧栏底部的提示都是 `sideNotice`：从上到下依次是这张、"已就绪"卡片、操作报错，前两张是强调色淡底、刷新图标加标题，报错是红色淡底、警示图标加原文，都和项目列表分得开。
- 自动更新（`internal/app/appupdate.go`，方案见 `docs/plans/mac-update.md`）：只有装在「应用程序」里、带更新地址的正式包才检查（`build/` 里的包在设置「关于」提示移到「应用程序」，PosseDev 不显示）。窗口启动 10 秒后、每 30 分钟、从睡眠唤醒时，距上次成功检查满 6 小时就查（时间在 ui.json 的 `updateCheckedAt`），菜单「检查更新…」和设置里的按钮随时查。新版本在后台下载、解压到 app 旁边，不换包；侧栏底部出现"Posse x.y.z 已就绪"卡片（✕ 后这个版本不再出卡片，记在 `updateDismissed`），设置「关于」的更新卡片显示状态和 CHANGELOG 里的更新内容。点「重启更新」：先处理未保存的文件，再换包、把常驻进程交接到新包、重开窗口，终端不断；不点的话退出 Posse 时换上。后台检查失败不提示，只写在设置里。
- 主区域状态栏右边的终端和内存按钮打开浮窗：posse 自己（常驻进程、窗口）和各工作区终端里的程序。终端按整棵进程树统计 phys_footprint，浮窗开着时每 3 秒按工作区算一次；底栏显示的是总内存（posse 自己加终端），终端合计每 5 秒算一次，窗口隐藏或最小化时不算。点终端展开进程明细：shell、agent 本体，和 agent 拉起的每棵子进程（MCP 服务等），名字取自命令行，跳过 npm、node、python 这类启动器。
- 新开的终端在程序画出第一屏之前居中显示蜂巢加载动画和"正在启动 Claude"（shell 终端写"终端"；动画和手机端同一设计：七格蜂巢，外圈顺时针逐格亮起、拖一段渐暗，1.2 秒一圈，减少动态效果时停在一帧）：先跑用户的 shell 配置再启动 agent，Claude 要一两秒才画第一屏，不提示像是没反应。接入 300ms 后才显示（切到已有内容的终端时快照还没到，不闪一下），屏幕上出现过内容或 20 秒后不再检查。
- 和会话有关的按钮在 agent 终端内容区右上角竖排一列：worker 终端的"返回任务"、图片、"技能与工具"；历史按项目，在文件栏的"历史"页。这一列盖在终端内容上，鼠标不在上面、也没开着它的面板时半透明；底部的箭头把它收成贴着右边缘的小把手，点把手展开（ui.json 的 `sessionButtonsHidden`，所有会话共用）。
- "图片"面板（`images.go`，四家会话都有）顶部是「生成」「粘贴」两段（带各自的数目），一次看一组；没点过时默认看生成的，生成的为空、粘贴的有就看粘贴的，换会话后重新按这条选。生成的——Claude、Grok 是工具结果里内嵌的图片（截图 MCP、读进来的图片；`history.ImageScanner` 按 agent 增量扫会话文件，只记位置，用到时按偏移读回那一行。Claude 只认 `type: user` 的行，`api-request-blob` 是副本；Grok 认 `tool_result` 的 `images`，和紧跟在工具结果后面、`synthetic_reason` 不为空的用户消息里的图片），Codex 是 `~/.codex/generated_images/<会话 ID>/`（`ig_` 图像生成、`exec-` 代码产出），Cursor 的会话文件不记工具输出，没有；Claude、Codex、Grok 工具输出里提到的视频文件（androidmirror 录屏返回的路径、命令打印的产物等，`history.VideoScanner` 只认工具输出里的绝对路径，磁盘上还在的才列）也算 agent 生成的，和图片按时间排在一起（Grok 的会话文件没有时间，排在后面），缩略图由 `qlmanage` 取第一帧（缓存在 `$TMPDIR/posse-video-thumbs/`，key 带文件修改时间，录到一半取不到的写完后再取），盖一个播放标记，点开用默认应用播放；粘贴的（`[Image #N]`）：Claude 取会话图片目录，Codex 取会话文件里用户消息的 `input_image`（序号取前面的 `<image name=[Image #N] path=…>`；那个临时文件之后可能没了，不读它），Grok、Cursor 取用户消息里 `<image_files>` 列出的文件（各自的 assets 目录，序号是清单里的编号，时间取文件修改时间）。只留缩略图，agent 生成的最多列最近 40 项。悬停在面板左边浮出大图，宽不超过 544、高不超过内容区，竖的长截图整张看得见；点图片在文件标签里预览（可缩放，用预览标签，同时收起面板），视频和不在任何工作区的用默认应用打开；右键有"在访达中显示"和"用系统预览打开"（指定 Preview.app，视频是"用默认应用打开"）。内嵌的图要打开、显示时先从会话文件写到 `$TMPDIR/posse-images/`（是 agent 当时看到的样子）。
- "技能与工具"面板由窗口进程增量只读解析当前终端的会话文件（`history.UsageScanner`），路径优先用 hooks 报的 `transcriptPath`，否则按会话 ID 在各家目录里找；只认实际使用的记录（注入的技能说明、读 SKILL.md 的调用、MCP 调用），系统提示里的技能列表不算。agent 执行的 shell 命令（Claude 的 Bash、Codex 的 exec_command 和 CommandExecution（同一个 id 只算一次）、Grok 的 run_terminal_command、Cursor 的 Shell）由 `history.cliPrograms` 做轻量解析认出运行的程序（引号、分隔符、`$( )`、`<( )`、heredoc、环境变量赋值、sudo/env/timeout 这类包装、`bash -c`、命令里定义的函数），shell 内建和 ls、cat、grep 这类基础工具（`cliSkip`）、相对路径和 Homebrew、系统目录以外的绝对路径不算；来源按本机安装位置判断（`cliSource`：/opt/homebrew，或 /usr/local/bin 下链接到 Cellar 的是 Homebrew，/usr/bin 等是系统自带，其余是其他命令行），一条命令里每个程序记一次。面板顶上是筛选（全部 / 技能和 MCP，记在 ui.json 的 `usageSkillsOnly`，只看技能和 MCP 时不列命令行程序的分组、时间线里也跳过它们），然后是每个技能、MCP 服务的次数，命令行程序按 Homebrew、其他命令行、系统自带分组，下面是时间线（`Usage.Events`，技能和 MCP、命令行程序各留最近 300 次，命令行刷得再多也挤不掉技能；取每行的 timestamp，grok、cursor 的会话文件没有时间），连着调同一个工具合成一项。标签和时间线里的名字点一下复制到剪贴板（底部提示已复制）。手机的"技能与工具"页内容相同，由常驻进程读（见 `mobile.md`）。
- agent 图标：Claude 取自 simple-icons，Grok、Cursor 取自 LobeHub Icons，都是单色填充路径，放在各家颜色的方块里；Codex 已并入 ChatGPT 应用，用 LobeHub 的 OpenAI 标志，照 ChatGPT 应用图标是白底黑标，加一圈细内描边免得在浅色卡片上融掉。
- 鼠标指针照 Orca（网页习惯）：能点的元素（按钮、链接、列表的可选行等）都是手形，禁用的是箭头，拖动排序、拖文件时是抓握的手；文字输入、终端、编辑器是 I 形，拖边调宽是左右或上下箭头。
- 终端标签可以改名：双击标签或右键「重命名…」原地编辑，回车或点别处保存、Esc 取消，清空或右键「恢复默认名称」回到会话标题或终端标题。名字由常驻进程记着（`terminal.rename`，存在 `terminals.title`，交接后从数据库读回），手机的标签也用它，优先于会话标题；标签、侧栏会话行和内存浮窗都用它代替会话标题和任务标题。界面先把名字记在 ui.json 的 `termNames`，马上换上，常驻进程报上来的一样了才删。
- 菜单（加号、右键、防休眠档位、分支、日志筛选等）都是同一种浮层：悬停是中性透明底，可勾选的项是陶土色对勾，快捷键右对齐（只是提示，不绑定，按快捷键表显示当前的键），子菜单在右边展开；↑↓ 移动、→ 展开子菜单、← 收起、回车选中，Esc 或点外面关掉。右键菜单贴着指针，放不下时翻到另一边。文字输入框、可选文字和编辑器的编辑菜单（剪切、复制、粘贴、全选，编辑器还有注释、选择、转换、折叠）样子相同、菜单项是中文。
- 鼠标照 Orca：终端标签和文件标签中键关闭、右键菜单（关闭、关闭其他、关闭右侧；终端标签另有复制引用、复制终端 ID，是任务 worker 时有复制任务 ID，有 agent 会话时有复制会话 ID。复制引用是贴给 agent 的一行字，写明名字、终端、任务、会话的 ID 和查看它们的命令，如 `Cursor「修登录」：终端 t_x（posse terminal read t_x），任务 k_x（posse task show k_x），会话 …（posse history show …）`；文件标签另有关闭所有文件、复制路径、在访达中显示），终端标签悬停提示完整的名字和标题。标签放不下时用触控板或滚轮左右滚，切到哪个就滚到哪个；照浏览器的标签栏不显示滚动条。标签文字选中时不加粗、只换颜色，切换时标签宽度和截断位置都不变；标题超过标签最大宽度（280）时截断加省略号，关闭按钮始终留在标签里。终端的右键菜单由 Posse 提供（`termmenu.go`，`terminal.Options.ContextMenu`）：复制、粘贴、全选、清屏（和 ⌘K 一样由常驻进程清）、复制会话 ID、关闭终端。从访达或文件栏（文件树、改动列表）拖文件到终端贴入路径：图片按粘贴发（agent 认得出粘贴的图片路径，当成附件：都认 png、jpg、gif、webp，另认的按 agent 不同，见 `imageExts`），有特殊字符时用反斜杠转义（路径带单引号时 Claude、Grok 认不出单引号括起来的写法），Cursor 连这个也认不出，改发 `file://` 链接；其余文件单引号转义后当键入、后面带空格；文件栏滑进来的途中不能拖。
- 终端里的链接：鼠标放上去有下划线和手形指针，原地单击或 Cmd+点击打开，拖动是选文字，程序开着鼠标跟踪（Claude、Codex）时也一样、这一下不交给程序（改在 `third_party/mygo` 的终端插件里）；指向不存在文件的链接不显示下划线、点不了。终端环境带 `FORCE_HYPERLINK=1`（和 Orca 一样），Claude Code 才会把 `[Image #N]` 输出成超链接。单击弹出链接卡片，Cmd+点击直接打开，Shift+Cmd+点击交给系统（`internal/app/links.go` 的 `openLink`）；设置「通用 › 终端链接」的「单击直接打开」（ui.json 的 `linkClickOpens`）把单击和 Cmd+点击反过来，卡片里对应操作右边的按法提示跟着换。网址的卡片是网址和后面的复制按钮、在 Posse 中打开、在浏览器中打开；直接打开是在网页标签里打开（不是 http、https 的交给系统），交给系统是默认浏览器。文件链接（如 Claude 的 `[Image #N]` 指向的 `file://`；没做百分号编码时 `#`、`?` 会被截掉，截出来的路径不存在才按原文再认，截出来的文件本身在就用那个）和路径的卡片：顶上是路径和后面的复制按钮，下面是在文件标签中打开（排第一，跳到路径带的 `:行`）、在文件栏中显示（打开文件树、展开上级目录并选中它，只认当前工作区里的路径；当前文件换了或在树上点了别的就不再选中它）、打开、在访达中显示；直接打开时文件在文件标签里打开（放进文件所在的工作区，不在任何工作区里的放进终端所在的工作区）并跳到行，目录在文件栏中显示（不在当前工作区里的弹卡片）；交给系统时文件用默认程序打开，目录在访达中打开。终端自动换行的、程序在路径的 `/` 后自己换行的链接按整条识别，悬停、点击哪一行都是完整的链接。
- 终端里查找（`termfind.go`）：⌘F 打开右上角的查找栏（快捷键表「终端 → 在终端里查找」；有单行选区时拿它当搜索词，关了再开接着搜上次的词；⌘F 后紧跟着打的字在输入框拿到焦点之前就到了终端，由终端插件的 `OnText` 交回来接进搜索词，不发给程序），搜索交给终端插件里 libghostty 的 find：窗口这份内核的屏幕和回滚区（4 MB，和常驻进程一样），只认原文、ASCII 字母不分大小写，不支持正则和整词；程序还在输出时命中跟着变，回滚区大时分帧搜、计数边搜边涨。命中铺蜂蜜色淡底，当前那个深一点（和 Markdown 预览的查找一样），右边是第几个 / 共几个，1 是最新的。回车、⌘G 往上（更早的输出），⇧回车、⇧⌘G 往下（按键跟着编辑器的查找下一个、上一个；栏开着时 ⇧⌘G 不去开关改动页），Esc 关掉并清掉高亮，焦点回到终端；全屏程序里查的是它那一屏。状态跟着终端视图走，切到别的终端或别的页面就关掉；被常驻进程断开、重新接入时照旧开着、按原来的词再搜；终端改了尺寸丢了选中时选回最新的。agent 终端的查找栏多一个历史按钮，搜不到时下面一行"在历史里搜"：Claude 重画时连回滚区一起清掉、Codex 在备用屏幕上，终端里只搜得到眼前这一屏，点了带着这个词、按这个 agent 筛选跳到历史页。
- 网页标签（`internal/app/web.go`）：http、https 网址在当前终端所在工作区的文件标签里打开，用系统的 WebKit（mygo 的 `WebView`），和 diff、比较一样不对应磁盘文件、不记进 ui.json，每次新开一个标签，打开后键盘交给页面。标签上是地球图标和页面标题（还没有标题、或新页面没有 `<title>` 时是主机名），悬停提示网址。上面一行是后退、前进、重新载入（载入中换成停止）、地址栏（没写协议的补 `https://`；localhost、IP 地址和 `.local` 补 `http://`，开发服务器一般没有证书；不像网址的不跳；Esc 恢复当前地址并把键盘交回页面）、复制链接、在浏览器中打开。载入失败（比如开发服务器还没起来）时页面位置写「打不开 <网址>」和原因，地址栏留着原网址，重新载入按原网址再试；被新跳转打断的不算失败。页面里 `target=_blank` 和 `window.open` 的链接在旁边再开一个网页标签（工作区已经不在了就交给浏览器）。跳转、载入、标题由页面事件更新；单页应用用 pushState、hash 换地址不发事件，网页标签看得见时每秒再对一次地址和前进后退。页面跑在系统的 WebContent 进程里（不算进窗口的内存），切到别的标签时留着，关掉标签、工作区换了目录或被删时销毁；窗口进程在第一次打开网页后多出 WebKit 框架约 20 MB，关掉也不回落。窗口被别的窗口完全挡住时 mygo 不画、WebKit 也不渲染，露出来再补上。
- 完成未读（`internal/daemon/unread.go`、`internal/app/unread.go`）：agent 从工作中变成空闲、又没有手机开着这个会话时，常驻进程记成未读，和手机共用（交接时带过去，常驻进程重启就没了）；窗口有焦点、正看着这个会话时报 `terminal.seen` 清掉，报之前它自己不画铃铛，手机开着它的终端页或会话页也算看过。标签、侧栏会话行和收起的项目、工作区汇总都画铃铛（汇总里次于待处理、高于工作中），未读期间铃铛隔一会儿摇一轮（摇 800 ms、来回摆三下越摆越小，再停 1.6 s；系统设了减少动态效果时不摇），侧栏会话行在铃铛前写"已完成"；它再开始工作也清掉。
- 系统通知和 Dock 角标（`internal/app/app.go` 的 `noticeStatus`、`noticeTitle`、`badgeCount`，任务的在 `tasks.go`）：由窗口进程发，关掉窗口后就不再有（窗口进程跟着退出）。窗口每次轮询比较每个 agent 终端的状态：进入待处理时发「<Agent> 等待你处理」；从工作中变成空闲且常驻进程记成未读时发「<Agent> 已完成」（手机看着时完成的不算未读，不发）；窗口有焦点、正看着这个会话时不发；窗口刚打开的第一轮只记下状态。正文是工作区名，后面接 agent 的最后一条消息。通知 ID 是 `posse:<工作区>:<终端>`，同一会话的新通知替换旧的，按工作区分组，点通知切到那个会话并把窗口提到前面。任务的问题、完成、失败、worker 意外退出另发（`posse-task:<任务>`，点开是任务页）。Dock 角标是侧栏显示成待处理和铃铛的 agent 会话数（按 `sessionStatus` 算：等待任务、还没恢复的不算，正看着的会话完成了不算），轮询的数据变了、看着的会话换了（含窗口失去焦点）时重算，数变了才更新。设置页「通用 › 通知」可以分别关掉通知和角标，关掉角标时马上清掉。
- 窗口最小 900×560：默认宽的侧栏旁边，默认字号的终端还有约 75 列。窗口窄时主区域状态栏先裁掉左边的套餐用量，右边的按钮不被挤掉。
