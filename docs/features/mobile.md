# 手机遥控

`internal/mobile`（常驻进程里的手机服务）和 `mobile/` 的 Flutter 客户端（Posse 手机客户端）。

## 连接与配对

- 兼容 Orca 的手机 App（App Store / GitHub 上的 APK）：posse 扮演 Orca 桌面端，协议照 stablyai/orca 的 `mobile/` 和 `src/shared/` 实现。不经 Orca 的云端中转（Orca 的 local-only），也不做推送（推送只能经 Orca 的网关）。手机 App 在前台时每 3 秒轮询 `worktree.ps`，靠它看到"待处理"。
- 常驻进程在 `0.0.0.0:6788` 开明文 WebSocket（避开 Orca 的 6768，两边可同时开），安全靠 E2EE v2（X25519 + HKDF + secretbox）和设备 token。没有配对过的手机时不监听，生成配对码时才开始。
- 配对码在侧栏「历史」下面的「手机」页、「新建」菜单（侧栏底栏最左边的 +）或 `posse mobile pair`：
  - 地址默认自动选（Tailscale 优先，其次局域网）；也可以自定义（配对对话框，或 `posse mobile pair --address`），规则照 Orca 的 `pairing-endpoint.ts`：主机或 主机:端口 拼成 `ws://`，完整 URL 的 http/https 换成 ws/wss、路径保留，用于隧道或反向代理（服务端不看请求路径）。
  - 手机页的地址下拉列出自动、检测到的每个 Tailscale 和局域网地址（取码时刷新）和用过的自定义地址；选的地址和用过的自定义地址存在 ui.json 的 `mobileAddress`、`mobileAddresses`。
  - 配对码 JSON 另有 `endpoints`：Posse 手机客户端同时连其中所有地址，先握手成功的留下。自动时是本机所有 Tailscale 和局域网地址，选了具体地址时只有它。Orca App 只读 `endpoint`。
- iOS 的配对页和首页的「添加电脑」可以扫码，只认二维码：扫到不是配对码的码相机不关，认到配对码才关相机去连；拒绝相机权限或开不了相机时回到配对页粘贴。安卓只能粘贴配对码。
- 连上后底部提示连的是哪台电脑、实际走的哪个地址，电脑列表里当前那台也写实际地址。手机上的电脑按公钥加主地址认：同一台电脑扫远程和局域网的码存成两项，可以来回切，没改过名的名字后面带地址区分。
- 权限按用到的时候要：国行 iPhone 打开 App 时弹「无线数据」，点扫码要相机，第一次连局域网地址时弹「本地网络」。第一次配对（手机上还没存过电脑）连不上时每秒重试，App 在前台累计 30 秒才放弃（弹窗开着时不计时，点完允许就连上），放弃时提示检查电脑和这两项权限。电脑明确拒绝（密钥不对、拒绝能力声明）不重试；配对过的电脑只连一次。
- 主机密钥和配对的手机存在 `$POSSE_HOME/mobile.json`（0600）。手机按公钥认主机，换密钥等于所有手机重新配对。每扫一次码多一个设备 token；Posse 手机客户端每次握手在 `runtime.clientCapabilities.update` 里带 `phone`（安装 ID、型号、它存着的这台电脑的全部 token）：同一台手机的 token 合成一项、名字换成型号，它不再存着的 token（重新扫码换掉、手机上删掉的）作废，没认领的旧 token 在它手里就归过来。Orca App 和旧版客户端不报，手机页收在"其他配对"里，可以全部移除。
- 桌面侧栏「手机」行尾：有手机连着时一个绿点（不止一台时前面写台数），悬停写是哪几台。来自 `daemon.status` 的 `mobileOnline`（同一台手机配对过几次只算一台），不用打开手机页。
- 主动断开：首页电脑胶囊打开的电脑列表里有"断开连接"（连着或正在连时才有）。断开后配对留着，这次运行里不自动重连；胶囊写"电脑名 · 已断开"、灰点不转圈，首页列出配对过的电脑和台数，点一台就连，底下可以扫码添加。
- 连不上：一开始就没连上（冷启动、切电脑、点重试都失败），手机不在后台重连，页面中间是报错和「重试」，胶囊写"电脑名 · 连不上"、红点不转圈。只有连上过之后断线才在后台一直重连，胶囊才是琥珀色的「连接断开，正在重连…」。
- 电脑列表弹窗：标题和底下的断开连接、扫码添加电脑固定，电脑多了只滚中间的列表；弹窗不到 360 高（横屏）时整张一起滚，免得列表被压没。

## QUIC 与中转

只有 Posse 手机客户端；Orca App 不认 `posse.quic`，照旧走 WebSocket。

- 手机服务在 WebSocket 同一个端口号上开 UDP 的 QUIC。一条连接只开一条双向流，上面跑和 WebSocket 一样的文本、二进制消息（u8 类型、u32 长度），握手、E2EE、RPC 全部照旧。TLS 只当传输加密，证书每次启动自签、手机不验，身份靠 E2EE。关闭时先发关闭帧（u16 关闭码加原因）再关流，排在正在写的消息后面。电脑读手机的消息上限 4 MB，和 WebSocket 一致。
- 手机每次连上都调 `posse.quic`，拿到端口、本机的 Tailscale 和局域网地址、中转地址和这台手机的令牌，换成 `hquic://主机:端口`（中转的带 `?relay=令牌`）存进这台电脑的记录，冷启动直接拨。这次走的是 WebSocket 时并发拨号，先握手成功的换掉 WebSocket，都不通就留在 WebSocket。之后的重连 QUIC 先连，WebSocket 晚 2 秒起跑兜底。经隧道的 WebSocket 只剩第一次配对和 UDP 不通的网络。
- 中转：`$POSSE_HOME/desk.json` 配了中转（和看桌面同一个 `tools/deskrelay`）时，每台手机第一次调 `posse.quic` 时 Mac 给它开一个 UDP socket，用这台手机的令牌每 10 秒向中转登记。令牌存在 mobile.json 的设备记录里（`relayToken`，设备列表不给出），一台手机一个，常驻进程重启、交接都不变。解除配对时关掉，换了中转地址全部重开。desk.json 每次调用都重读，改了不用重启。手机经中转时先登记、等到回执才握手，中转 1.5 秒不应答就失败。
- 打洞：经中转连上后在后台打洞。手机新开一个 socket，向中转发探测包问出它的公网地址，经 `posse.punch` 交给 Mac；Mac 从这台手机的中转出口问出自己的公网地址回给手机，同时从这个出口向手机的地址连发 4 秒打洞包；手机也从新 socket 向 Mac 的地址连发打洞包并拨 QUIC。3 秒内握手成功就换过去（显示「直连 · QUIC」），打不通（比如两边都是对称 NAT）留在中转。直连的地址不存：断了先连中转，再重新打洞。
- 换连接时旧连接等页面在新连接上订阅好、进行中的请求回完再关（0.5 到 10 秒），电脑上的终端不会被改回电脑尺寸再改回手机尺寸。
- 电脑列表和连上的提示里写「地址 · QUIC」或「经中转 · QUIC」。手机上的 QUIC 是编进 App 的 Go 库（`mobile/packages/posse_quic`，构建见 `mobile/README.md`），iOS、安卓共用。

## Posse 扩展协议

- `runtime.clientCapabilities.update` 声明的能力记在这条连接上，没声明能力的连接不收 Posse 扩展推送，也调不到要能力的方法。
- `runtime.ping`：不用声明能力，电脑立刻回空结果。
- `posse.permission.v1`：正在订阅某个终端对话时，Claude 的 PermissionRequest 走 `hook.permission.hold`：往这条对话流推 `type:permission`，等 `agent.permission.decide`；桌面有人键入或 30 秒到了就返回空 behavior。
- `posse.git.v1`：只读的 `git.status`、`git.diff`（拒绝绝对路径和 `..`；图片的 diff 另带 `images`：HEAD 里的旧图和工作区的新图，base64）。checkout、commit、push 不开放。这两项在常驻进程里，不走窗口进程的 Git 界面。
- `posse.history.v1`：`history.list`、`history.search`、`history.resume`，转给常驻进程同名的接口；resume 回终端 ID 和手机上的工作区 ID，报错是中文。看会话内容走 `nativeChat.readSession`（按会话文件读，claude、codex、grok、cursor 都认；cursor 的记录没有工具结果，时间只有用户消息开头的 `<timestamp>`）。手机上不能移到废纸篓。
- `posse.context.v1`：`session.context`（参数同 `nativeChat.readSession`），读会话最后一次请求的上下文，claude、codex 才有。
- `posse.status.v1`：对话流里另收 `type:status`。终端一有输出，就从屏幕最后一行有字的往上 16 行里认出 agent 的状态行（Claude 的 `✻ Puzzling… (1m 54s · ↓ 9.5k tokens)`、Codex 的 `• Working (12s • esc to interrupt)`），去掉转圈符号、按键提示和"thought for"，变了才推，最多每 250ms 一次；状态行消失时推空串。
- `posse.bulk.v1`：大块数据走二进制帧。`files.readRange`、`files.readPreview` 的图片、`session.mediaThumb`、`session.mediaRead`、`git.diff` 的图片，这些结果里的字节字段拆成 64 KB 的二进制帧先发，JSON 回复里只写 `blobs: {字段路径: 编号}`，手机按编号拼回。帧头 8 字节：`0x62`、版本 1、操作、0、u32 编号（小端），和 Orca 终端流的 `0x74` 区分。上传时 `clipboard.startImageUpload` 带 `expectedBytes`，电脑回一个编号，手机把原始字节按 64 KB 的二进制帧连续发完再 `commitImageUpload`；电脑边收边写临时文件，最大 1 GB，视频、文件也走它。带 `name`（手机上的文件名）的放进新建的临时目录 `posse-mobile-*/原名`，没带的按开头的字节认扩展名（jpg、gif、webp、heic、mov、mp4，认不出当 png）。不回编号的旧电脑照旧一段段传 base64（最大 32 MB）。
- `posse.media.v1`、`posse.desk.v1`：见下面「图片与视频」「看 Mac 桌面」。
- 映射：项目 → repo，工作区 → worktree（ID 是 `<项目 ID>::<工作区 ID>`），运行中的终端 → 标签（手机只认 UUID 形状的 leaf，由终端 ID 派生；标签名依次取桌面改的名字、会话标题、终端标题）。agent 状态 waiting → `waiting`（行状态 `permission`），working/starting → `working`，idle → `done`。
- 电脑按顺序处理同一条连接的请求；要读盘、调 git、等索引或联网的（`files.*`、`git.*`、`history.*`、`session.context`、看图看视频、`usage.refresh`、打洞）各自并发，不挡按键和 ping。一条消息写了 3 秒还没写完、手机也有 10 秒没发任何东西来，就当连接已死马上断开，手机随即重连。
- 输入框发来的文字（`terminal.send` 的 `text`）带换行、程序又开着括号粘贴（DECSET 2004）时，包在 `ESC[200~`、`ESC[201~` 之间当成一次粘贴送进去，Claude Code 显示成「[Pasted text #1 +N lines]」；回车隔 120ms 单独发。

## 延迟和断线

- 手机每 5 秒 `runtime.ping` 一次（旧常驻进程没有它时用 `status.get` 计时）。会话页、终端页标题下面的状态行在上下文后面写最近 3 次中位数的信号格和毫秒数：150 ms 内满格绿色，到 300 ms 两格灰色，300 ms 起一格琥珀色，没响应是带感叹号的红色空格加「无响应」。首页顶栏同一个读数排在右边按钮组最前面、左右空出和图标按钮一样的间距，断线重连时不显示；电脑胶囊用掉剩下的宽度、靠左，里面只有连接圆点和电脑名，胶囊变宽变窄读数不挪；右边的历史、新建、设置用紧凑尺寸（40）给它腾地方。一次 ping 期间连接上收发超过 64 KB 的样本不算。
- 等 5 秒没回、期间也没收到任何请求的回复，写「无响应」并马上补测；连续 3 次就断开重连，切网络、手机休眠后的半开连接 15–20 秒内发现。终端输出、标签这类推送不算活着。
- 从后台回到前台（拉下控制中心不算）时马上 ping 一次，2 秒内没有任何回复就断开重连；本来就断着、正在两次重试之间等的，马上连。

## 终端页

- 尺寸：手机看终端时终端按手机屏幕排版，界面这时的尺寸变化先记下，手机全部离开后恢复（行数变多的处理见 AGENTS.md「界面接入终端」），手机的流随后重发快照。手机接入不接管终端查询的应答。手机本地尺寸变过就重新订阅拿快照，尺寸停止变化 150ms 后才订阅一次。
- 改回电脑尺寸：终端被手机占着尺寸时 `terminalInfo.phoneSized` 为真，窗口在终端上方显示一行提示和"改回电脑尺寸"（`terminal.reclaimSize`：放掉所有手机的占用、按界面最后要的尺寸重排；手机的订阅还在，重新打开这个终端才会再占）。手机切到后台时连接常常还挂着，不然电脑上一直是窄的。
- 电脑布局：终端的"更多"里有"电脑布局"，订阅时不带手机尺寸，终端保持电脑的列数和行数，手机把格子缩进屏幕宽度（双指放大吸到 0.5–2 的固定档后再滑），不改 PTY 尺寸。上下拖动照常平移。
- 键盘：弹出、收起不改终端尺寸。快捷键栏贴着键盘上移，终端整体往上挪到最后一行内容（有字或铺了底色的最后一行和光标所在行取靠下的）露在快捷键栏上方，最多挪键盘盖住的高度；shell 刚开、内容在上半屏时不挪。提示和上传进度浮在看得见的那块上。点终端（含电脑布局里格子外的空白）只在键盘收着时弹出，弹着时不收；收起键盘用快捷键栏最前面的键盘键。点链接不动键盘。
- 画面：弹出、收起键盘或从后台回来后，Claude Code 改尺寸重画时不变的行（分隔线、状态栏）照常画出；推入动画结束、回到前台、agent 从工作中停下来时重取一次画面。终端输出走 Orca 的 16 字节头二进制帧，按 UTF-8 字符边界切块。等宽字体回退链带 App 自带的 Symbols Nerd Font Mono（MIT），提示符里 Nerd Font 的图标能显示。
- 选区：长按选中词（不震动），两端有把手，松手后拖把手改范围，点终端空白取消；宽字符按整字选。选区上沿有「复制」和「全选」（放不下就改到这一行下面），全选扩到当前段落（上下遇到空行停下）。复制不带末尾的换行。
- 粘贴：快捷键栏的粘贴、系统菜单的粘贴、听写这类一次插进好几个字又带换行的输入，都按一次粘贴送进去（开着括号粘贴就包起来），去掉末尾的换行，粘贴完停在输入框里、不直接发出去。
- 链接：轻点网址交给系统浏览器，指向工作区里文件的路径（含 `file://`）在文件页里打开，工作区外的提示打不开。
- 滚动：全屏程序跟踪鼠标时，手指滑动换成的滚轮报在手指所在的格子；不跟踪鼠标时，只在程序开着 1007 时换成方向键，和桌面一致。
- flterm 的改动见 `mobile/third_party/flterm/POSSE.md`。

### 快捷键栏

- 最前面是切换系统键盘的键盘键；后面的键在设置里可排序、加自己的键。内置键默认顺序：发送文件、粘贴、（自己加的键）、Esc、Tab、Enter、立即发送（键帽 ⌃↩）、⇧Tab、^C、清空、Exit、方向键。新版本加的内置键插在默认顺序里它前面那个键后面。
- 发送文件（回形针）：先放下键盘，再从相册选照片或视频、拍照、或从「文件」App 选，传到电脑后把路径当一次粘贴打进终端、不回车，路径里的空格、括号等加反斜杠（和把文件拖进 macOS 终端一样）。
- 清空：agent 终端里删掉整个输入框（Ctrl+E、Ctrl+U、退格逐行删，最多 40 行），不用 Esc、^C（干活时是打断）；shell 终端只删当前行。
- Exit：清空输入框后执行 `/exit`（Claude Code、Codex、Grok、Cursor 都认），清空、命令、回车之间各隔 300ms；不发 Ctrl+D，免得多出来的一次把 shell 也关了。没在运行 agent 的终端只提示。
- 立即发送：Claude Code 的 `chat:sendNow`，干活时排着队的消息马上交给模型。实际发的是同样绑定的 Ctrl+X Ctrl+S（Ctrl+Enter 要 kitty 键盘协议，手机终端发不出）。
- 方向键、Home、End（内置和自定义）按程序当前的光标键模式编码：开着应用模式（DECCKM）时发 ESC O A，htop 这类 ncurses 程序只认这种；`posse terminal send --key` 也一样。

## 对话页与历史

- 会话页、终端页标题下面的状态行：agent 状态（照 `type:status` 写，没有时写正在用的工具）、「上下文 N%」、延迟。上下文每 15 秒和状态变化时重读，75% 起琥珀色、90% 起红色；点它弹框问要不要压缩，确认后先清空输入框，再往终端发 `/compact` 和回车（Claude、Codex 都认）。
- Claude 的回复整段写完才进会话文件，对话页靠状态行表示还在干活。发出去的话先画在末尾（发送中半透明、终端收下后写已发送），会话文件里出现对应的用户消息后撤掉；斜杠命令不先画，5 分钟等不到也撤掉。
- 选图面板：相册可以多选照片和视频，另有剪贴板和「文件」。照片先预览、发送时传，视频和文件选了就传，路径一个一行接在输入框后面。上传的文件存在电脑的 `$TMPDIR/posse-mobile-*`，App 再把路径输入终端；上传时列表或终端底部浮着第几张和百分比，不占布局，终端不因此改尺寸。
- 历史：首页顶栏的时钟进历史。搜索框下面照桌面按 agent 筛选（全部、Claude、Codex、Cursor、Grok，列表和搜索都带 `agent` 交给电脑，每次进来从全部开始）。列表默认按今天、昨天、最近 7 天、最近 30 天、1 个月前分组，右上角可以换成按文件夹分组（规则同桌面：归到目录所在的项目，项目和它的工作区、worktree 取最长匹配，都不在的用目录名，组按其中最近的会话排；选择记在手机设置里），搜索结果按相关度排、不分组、带命中摘要；点开只读看对话（往上翻到头自动读更早的一页），底部"在电脑上继续"调 `history.resume`，提示里能直接在手机上打开那个会话。

## 文件与媒体

- 文件页：`files.readDir`（手机优先用，没有才退回 `files.list`）、`files.list`、`files.searchPaths`、`files.read`、`files.readPreview`、`files.stat`，只读，路径相对工作区、拒绝绝对路径和 `..`，限制照 Orca（文本 512 KB 截断、图片 10 MB、清单 5000 个）。音频、编辑保存、在桌面打开没做。
- 视频（mp4、mov、m4v、webm）由 Posse 扩展 `files.readRange` 分段下载（每段 1 MB，同时 2 段，每段等 60 秒、超时再试两次）到手机临时目录再播放，按路径、大小、修改时间缓存，超过 500 MB 不下。没下完时留着 `.part`，错误页的"接着下载"或下次打开从断处接着下。
- 从文件树点开图片或视频时，同目录的其他图片、视频按树里的顺序排成一组，左右滑切换，顶栏的文件名和存到手机跟着换（搜索结果、Git 页、链接打开的只看这一个）。
- Markdown：表格按内容宽排、一列最宽 220、太宽左右滑，任务列表画勾选框，嵌套列表逐层换圆点；相对链接和图片按 md 文件所在目录算，工作区里的文件在文件页打开、图片向电脑要（最近 24 张留在内存里），网址交给浏览器。文件页和对话页用同一套 GitHub 风格的解析规则。
- 源码、diff 和 Markdown 代码块在手机上本地着色（配色同桌面编辑器的 GitHub 深浅两套）：按文件名或围栏语言认，认不出不着色；超过 256 KB 不着色。源码和 diff 按行只建看得见的，选中复制时行之间有换行。

### 图片与视频

- 带 `posse.media.v1` 才有：会话页、终端页的"更多"里"图片与视频"，内容和桌面的图片面板一样。`session.media`（参数同 `nativeChat.readSession`）列出 agent 生成的（最近 40 项）和粘贴的；`session.mediaThumb` 给 480 像素宽的 JPEG 缩略图（视频取第一帧），一次只做一张；`session.mediaRead` 按段读原图或视频（同 `files.readRange`，每段 1 MB）。手机只能按列表给过的 ID 读。会话文件被重写后按旧偏移读不到时回「会话文件里没有这张图片了」。
- 手机上两列网格，开着时每 3 秒重列；点开图片是原图（agent 当时看到的样子），双指放大，视频和文件页走同一套分段下载和播放。左右滑切到前一项、后一项（顺序同网格：先生成的、再粘贴的，副标题末尾写第几项），翻走的页释放（视频停下、缩放不留）。原大时单指翻页，放大后单指平移。

### 存到手机

- 文件页、图片与视频页看大图或视频时顶栏右边有按钮，原文件取到手机上之后才能点（视频要等下完）；文件列表长按文件、图片与视频网格长按一格，弹出面板，现下（带进度、可取消、断了接着下）再存，任意文件都行，超过 500 MB 不下。面板另有"分享"，发给别的 App。
- 按格式定存到哪：jpg、jpeg、png、gif、webp、heic、mp4、mov、m4v 存进相册的「Posse」相簿（安卓在 `Pictures/Posse`）；其余格式和相册拒收的，安卓存进「下载/Posse」（重名时改成 `x (1).md`），iOS 弹系统分享面板（里面有"存储到文件"）。存的文件用原名（会话里粘贴的图片按文件头补扩展名）。
- 权限：相簿要相册的读写权限（iOS 选"限制访问"也行；安卓 10 及以下要写存储权限）。
- 同一个文件同时只有一个在下，边看视频边点存不会冲突。

## 看 Mac 桌面

实验功能，只有 iOS。取舍记录见 `docs/plans/phone-desktop.md`，界面调研见 `docs/plans/phone-desktop-ui.md`。

- 入口：设置里打开「实验：看桌面」后，首页电脑胶囊打开的菜单第一行是「看桌面」。
- 订阅：`desk.subscribe`（能力 `posse.desk.v1`，带屏幕像素、能解的编码（现在只有 hevc）和上次看的屏 `display`）是一个流：先回 `ready`（端口、编码、nonce；配了中转时带中转地址和令牌；支持补发时带 `nack: true`），之后推 `state`（辅助功能有无、锁屏与否）、`displays`，结束时推一条 `end`（`stopped`、`unsubscribed`、`no_report`、`capture_failed`）。UDP 的密钥用这条连接的会话密钥做 HKDF（`posse-desk/v1`）。`desk.unsubscribe` 或连接断开都会停掉采集。
- 同一时间只有一台手机能看，第二台订阅得到 `busy`（「另一台手机正在看」）。
- 锁屏：锁着屏照常看（ScreenCaptureKit 采得到锁屏界面），采集子进程报状态，常驻进程推 `state` 事件 `locked`、`unlocked`，观看不断。开始看时 Mac 已锁屏，子进程声明一次用户活动（屏幕熄了会点亮）并原地挪一下指针，唤出密码框。锁屏期间手机打的字按当前键盘布局逐个按键注入（密码框认按键），距上次唤出超过 5 秒先再唤一次。只看一个窗口时锁屏期间改看主屏，解锁后换回那个窗口（锁屏期间手机选了别的屏就不换回）。手机在画面上方显示「Mac 已锁屏」和「输入密码」，密码在底部弹层里输入，发过去后自动回车；发送前 Mac 已经解开了就不发。弹层里可以「记住密码」：发出后 15 秒内 Mac 报解锁才存（输错的不记），按电脑的主机公钥存在 iOS 钥匙串里（手机解锁时可读、只在这台手机、不进备份）；记着时胶囊上是「解锁」，一点就发，旁边的钥匙按钮重新输入或忘掉。打开「看桌面」后，设置的「实验」里写着记了几台电脑的密码，「全部忘掉」清空。旧常驻进程锁屏时仍回 `locked` 错误或以 `locked` 结束，手机写「Mac 已锁屏」，每 2 秒重新订阅。
- 授权：没允许屏幕录制时订阅得到 `permission_screen`；没开辅助功能时能看不能操作，画面上有提示，在 Mac 上打开后提示自动消失。Mac 的手机页在有人看或缺授权时多一张「看桌面」卡片（`daemon.status` 的 `deskViewer`、`deskMissing`）：写哪台手机正在看，「停止」（`desk.stop`）断开它的画面和操作；缺哪项授权各一行说明和「打开系统设置」。
- 线路：
  - 连接的主机是局域网、Tailscale 或本机回环时，UDP 直接发到它。走隧道时从同一台电脑存着的其他地址里挑第一个能直连的，订阅仍走当前连接；5 秒没出画面提示手机和 Mac 不在同一个局域网。
  - 一个都没有、Mac 在 `desk.json` 配了中转时，手机同时发往直连候选和中转，Mac 从哪条路收到就从哪条回，直连还通时不换到中转；10 秒没出画面提示直连和中转都不通。中转也没配时退订，提示在同一个 Wi-Fi 下扫这台 Mac 的局域网码或改用 Tailscale。
  - 画面经中转到了之后打洞，流程同上面「QUIC 与中转」的打洞，区别是手机用收画面的 socket 问公网地址、经 `desk.punch` 交给 Mac；打通了改发直连，打不通留在中转。调试面板的「线路」显示直连、中转或打洞直连。
- 弱网：
  - 3 秒没收到手机的报告先暂停发画面，20 秒内回来就接着发，20 秒还没回来才以 `no_report` 结束。切网络、进电梯断几秒不用手动重连；手机被强退时 Mac 的录屏和防休眠最多多留 20 秒。
  - 网络变差时先降码率（最低 400 kbps），再把帧率上限依次降到 30、15、10，15 帧及以下时画面长边减半；好转后码率先快后慢地回升，帧率和尺寸跟着升回。
  - 丢包时手机按序号点名要补发（`ready` 带 `nack: true` 时），Mac 从最近发过的包里补；补不回来才丢掉这一帧，停在上一帧等关键帧，不显示花屏。
- 采集出错：采集子进程出错退出（ScreenCaptureKit 停了流、编码连着失败 3 次）或 10 秒既没心跳也没画面时，常驻进程重新拉起它，接着看原来那块屏，码率、帧率和尺寸照旧，手机这一路不断，画面从新的关键帧接上；只看一个窗口时回到整块屏。重建前等 0.5、1、2 秒，一分钟内重建 3 次还不行就以 `capture_failed` 结束。没出新帧是画面没动，不算出错。
- 画面：选屏和只看一个窗口都在悬浮球的「画面」里，电脑报了屏就出现（一块屏也有）。面板上面是整块屏（多块时带按真实排布画的缩略图，下面是名字、分辨率列表），下面是窗口列表，每个窗口前面是它所属 App 的图标（Mac 按 App 给一份 64 像素的 PNG，取不到时画通用的窗口图标）。面板高度固定，内容在里面滚。
  - 多块屏（取舍见 `docs/plans/phone-desktop-displays.md`）：开始时、切屏后、拔插或改分辨率后，订阅流里推 `{type:"displays", current, displays}`（每块屏的 ID、名字、全局坐标里的点、像素，哪块是主屏）。点哪块屏经 `desk.display {id}` 切过去，缩放回到 1 倍。选的屏按电脑记住，下次订阅带上，那块屏不在就看主屏；看着的屏被拔掉回主屏。
  - 只看一个窗口（取舍见 `docs/plans/phone-desktop-windows.md`）：窗口列表在面板打开时经 `desk.windows` 现要（当前空间看得见的普通窗口，最前的在前面，去掉太小的、没有名字的）。点了经 `desk.window {id}` 只采这个窗口（别的窗口盖着也不进画面），画面是窗口的像素大小，Mac 上把窗口提到最前。点击、滚动按窗口当前的位置换算，按下前窗口被盖住或它的 App 不在最前时先提到最前。窗口改大小时画面跟着变；关掉、最小化或切到别的空间了回到所在的整块屏，displays 事件带 `gone`，手机提示几秒。只看窗口时 displays 事件带 `window`（ID、App、标题），面板里给它打勾。窗口不记，下次观看照旧从记着的屏开始。
- 收包、解密、补发、拆 RTP、硬解都在原生插件里（`mobile/ios/Runner/DeskSession.swift`、`DeskPlugin.swift`），解出的帧直接交给 Flutter 纹理，不经 Dart。
- 悬浮球：有画面后沉浸显示，只留一个悬浮球。上下左右都能拖，松手吸到最近的左边或右边；竖屏默认在右上角，横屏默认在没有刘海的那一侧中间。键盘和快捷键栏弹出时球留在它们上面。横竖屏各记各的位置，离开页面回到默认。收起时是连接质量的信号格（颜色和格数同延迟读数）和帧率，点开是返回、横竖屏（图标画当前的方向，点一下切到另一个）、键盘、快捷键、调试、断开；放大后双指缩回 1 倍，4 秒不碰收起；还没画面时一直展开。
  - 返回离开页面（左缘拖动是平移画面，不触发页面返回）；断开停掉这一路画面并留在页上，已经停了再点是重新连接。
  - 调试显示帧率、码率、丢包、已发和已确认的输入序号，可以改 UDP 地址。
  - 连不上或结束时画面中间是一张卡片：原因、要做什么，能重来时带「重试」或「重新连接」。
- 横屏：横竖屏按钮锁住方向，选择记住、下次进来照做。离开页面时手机不是横着拿就转回竖屏。横屏时画面铺满安全区的宽度，左右让开刘海。
- 键盘和快捷键栏：快捷键栏默认不显示，点悬浮球的键盘或快捷键才出现，系统键盘弹出时贴在键盘上方；横屏时半透明、更矮。它们盖在画面上，画面不缩；最后单击的那一处会被盖住时，画面整体上移到它露出来，收起后回原位。修饰键点一下只管下一个键、长按锁住。系统键盘打的字只发新打的，删掉的每个字发一次退格。快捷键栏在方向键后面多「◀ 空间」「空间 ▶」「调度中心」（⌃←、⌃→、⌃↑）。Mac 端注入方向键、Home、End、翻页、向前删除时照真键盘带上小键盘和 Fn 标志，调度中心这类系统快捷键才认。
- 手势：单指轻点单击（400ms 内附近再点递增击数）、双指轻点右键、长按 300ms 后拖动、单指拖平移视口、双指拖滚动（滚动落在手指下面的窗口，带惯性，内容贴着手指走）、捏合缩放到 4 倍，双指手势按头 10 像素的移动定性。三指横滑切空间，方向和触控板一样（手指往左划切到右边的空间），四指以上不认。长按进入拖动、双指右键各有一次轻触感。第一次进页面有手势提示，点任意处关掉。看桌面时屏幕顶边和底边的系统手势延后，离开页面恢复。
- 触控板模式（设置「实验」里看桌面打开后选「直接点按」或「触控板」，换了以后下次进页面再提示一次手势）：单指滑动按相对位移移 Mac 指针（手指慢时 1:1，快了加速到 2.5 倍，放大时按看得见的画面换算），点按、双指右键、滚动都落在指针上；拖动是轻点后 400ms 内再按住滑动，不用长按（手指放上去停一下再滑是移指针）；拖动中松手左键再按住 0.6 秒，期间放回手指滑动接着拖（屏幕小也能拖远），轻点一下或等过去才松开。指针从画面中间开始（Mac 不报指针位置），换了在看的屏或窗口（手动切、窗口没了退回整块屏、锁屏改看主屏）回到中间；画面上在手机算出的指针位置画一个圈，跟手，左键按着（拖动中、松手等续拖）时是实心，画面里的指针晚一个来回。放大后指针离边缘不到 36 像素视口跟着挪，点按、右键、拖动、滚动之前指针在视口外（捏合缩放后）也先挪到看得见，不再单指平移；捏合、三指横滑照旧。手指下面不画点。
- 输入经 UDP 发给电脑，必达事件没确认会重带。退到后台先把按着的键松开再退订，回到前台重新订阅。

## 外观

- 加载动画：整页加载是七格蜂巢，外圈六格顺时针逐格亮、后面拖一段渐暗；按钮里、行尾的小转圈是六边形描边。历史页还没有内容时整页是蜂巢，已有结果再读时转圈在搜索框里。系统开了减弱动态效果时停在一帧上。上下文用量的圆环、视频下载和上传的进度条用 Material 的。设计稿 `design/loading/concepts.png`。
